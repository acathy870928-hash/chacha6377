# 샘플 화면

서버 없이 **파일만 열어서** 화면을 볼 수 있게 만든 것입니다.
누구 컴퓨터에서든 더블클릭하면 열립니다. 인터넷도 필요 없습니다.

```
demo/ifanews-어드민-샘플.html
```

## 들어 있는 화면

| 화면 | 누가 보나 | 무엇을 하나 |
|---|---|---|
| 후보 고르기 | 사업단 대표 | 신호 점수순 후보에서 체크, 탭·검색·필터, 제외/대상 이동 |
| 공유 화면 | 사업단 대표 | 링크와 카톡 문구 생성, 기사별 한 줄 코멘트 |
| FA 화면 | FA | 브리핑 목록 → 기사(제목 + 본문) |

위쪽 메뉴로 오갈 수 있습니다. 실제로 눌러지는 화면입니다.

## 진짜와 다른 점

- **제목과 본문은 예시입니다.** 원문 링크만 실제 기사로 연결됩니다.
- **RSS 지금 수집**, **후보에 추가** 는 안내 문구만 뜹니다. 서버에서는 실제로 동작합니다.
- 고친 내용은 저장되지 않습니다. 새로고침하면 처음 상태로 돌아갑니다.

## 다시 만들기

화면(`app/static/*.css`)을 고친 뒤 이 파일에 반영하려면:

```bash
python3 demo/build_sample.py
```

실제 앱의 CSS 를 그대로 끼워 넣기 때문에, 이 파일에서 보이는 모습이
서버에 올렸을 때의 모습입니다. 샘플 기사는 `build_sample.py` 의 `ARTICLES` 에 있습니다.

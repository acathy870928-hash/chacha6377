# Insurance Vertical AI™

> Insurance, Augmented.
> **Protect Your If. Secure Your When.**
> *Creating the Future Standard of Insurance*

보험을 위해 태어난 AI. 범용 AI가 아니라 보험상품·보험법·보험약관·보험설계·보험소비자를 이해하는
버티컬 인텔리전스로, 보험을 **설명하는** AI가 아니라 보험의 **의사결정을 함께하는** AI를 지향합니다.

## 우리가 준비하는 두 가지 미래

- **If** — 질병, 사고, 예상하지 못한 위험과 같은 고객의 '만약'
- **When** — 은퇴, 장수처럼 반드시 찾아오지만 언제인지는 알 수 없는 고객의 '언젠가'

## 우리가 만드는 전환

| From | To |
| --- | --- |
| 판매 중심 | 고객 중심 |
| 경험 중심 | 데이터 중심 |
| 직관 중심 | 과학 중심 |
| 사후 대응 중심 | 평생 관리 중심 |

# 경영진 HR Index 대시보드

C레벨을 대상으로 한 **동적 인사 대시보드** 프로토타입입니다.
숫자만 있는 인사 데이터를 시각화하고, 인력 구성 변화 → 인건비 → 생산성으로 이어지는
예측치와 인사이트까지 함께 제공하는 것을 목적으로 합니다.

`index.html` 파일 하나로 동작합니다. 외부 라이브러리·네트워크 요청 없음. 브라우저로 열기만 하면 됩니다.

## 기능

| 영역 | 내용 |
|---|---|
| **시점 스크럽** | 2022 Q1 ~ 2027 Q4 분기 슬라이더. 2026 Q3부터는 예측 구간으로 구분 표시 |
| **묶음 기준 전환** | 조직 / 직급 / 직군 / 연령대 — 선택 즉시 모든 차트·테이블·인사이트가 재구성 |
| **비교 지표 전환** | 인원 / 인건비 / 인당 인건비 / 인당 생산성 / 인건비 비율 |
| **KPI 타일** | 총원, 연간 인건비, 1인당 생산성, 1인당 인건비, 인건비 비율 (전년 동기 대비 + 스파크라인) |
| **지수 추이** | 인건비·생산성·인원을 2022 Q1 = 100으로 지수화해 한 축에서 비교 (예측 구간 점선) |
| **인력 구성 추이** | 그룹별 누적 컬럼. 예측 구간은 빗금 처리, 막대 클릭 시 해당 시점으로 이동 |
| **인력 운영 시뮬레이션** | 채용 규모 · 퇴직률 · 임금 인상률 · 자동화 투자 4개 변수를 조정하면 예측 전체가 즉시 재계산 |
| **시나리오 프리셋** | 기준 / 성장 / 효율 / 긴축 — 기준 시나리오 대비 차이를 수치로 표시 |
| **효율 포지셔닝** | 인당 인건비 × 인당 생산성 버블 차트, 인건비 비율 30% 기준선 |
| **자동 인사이트** | 선택 조건에 따라 6개 문장이 자동 생성 (인건비-생산성 격차, 손익분기 생산성, 구성 변화, 효율 점검 대상 등) |
| **데이터 테이블** | 차트의 모든 값을 숫자로 확인 · 전사 분기별 시계열 포함 |

## 데이터

현재 수치는 **샘플 데이터**입니다. 실 데이터 연동 시 필요한 원천은 다음과 같습니다.

1. **인사마스터** — 사번 · 조직 · 직급 · 직군 · 생년월일 · 입사일 · 퇴사일
2. **급여** — 사번별 연간 인건비 (고정급 + 변동급 + 법정 부담금)
3. **경영지표** — 조직별 매출 또는 매출 기여액, 영업이익 (월/분기)

3번이 확보되기 전까지 생산성은 1인당 매출 기여액 추정치로 계산합니다.
산출 로직 전문은 화면 내 **데이터 안내** 탭에 정리되어 있습니다.

## 예측 로직 (2026 Q3 이후)

```
인원(t)        = 인원(t-1) × (1 − 퇴직률/4) + 채용/4
평균임금(t)     = (잔류인력 임금 × (1+인상률)^0.25 + 신규인력 임금) ÷ 인원(t)
                 └ 신규 인력은 기존 평균의 72% → 평균임금 희석 효과
인당 생산성(t)  = (잔류인력 생산성 × (1+g/4) + 신규인력 생산성 × 0.55) ÷ 인원(t)
                 └ g = 0.8% + 자동화 투자 지수 × 0.09%/년
```

채용을 늘리면 인건비는 즉시 늘지만 생산성은 지연되어 반영되므로,
"채용 확대 → 단기 효율 하락 → 자동화 투자로 상쇄" 구조를 화면에서 직접 비교할 수 있습니다.

## 접근성

- 계열 색상은 색각 이상(protan / deutan / tritan) 시뮬레이션 기준 분리도 검증을 통과했습니다.
- 모든 차트에 범례와 직접 라벨을 함께 제공하며, 색으로만 구분되는 정보는 없습니다.
- 전체 값은 데이터 테이블 탭에서 숫자로 확인할 수 있습니다.

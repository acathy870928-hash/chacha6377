# Insurance AI 보험상품 운영 규칙

Insurance AI의 보험상품 답변 운영 규칙 문서(v1.1)와 현재 판매 상품 데이터를 관리한다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `docs/insurance-ai-operating-rules.html` | 운영 규칙 문서 원본(HTML) |
| `docs/Insurance_AI_보험상품_운영규칙_v1.1.pdf` | 배포용 PDF (HTML에서 생성) |
| `data/current_sales_products.csv` | 현재 판매 상품 데이터 (예시, 개정코드 2607 기준 40건) |
| `scripts/build_pdf.sh` | HTML → PDF 렌더링 스크립트 |

## v1.1 개정 내용

1. **보험료 안내 시 최신 파일 기준 원칙 신설** (1-2항)
   - 보험료 관련 안내·근거 확인은 항상 최신 파일(최신 게시일·적용일)을 기준으로 한다.
   - 동일 상품군은 상품명 말미 개정코드(YYMM, 예: `2607`)가 가장 높은 자료를 최신으로 판별한다.
   - 과거 가입상품 질문은 예외로, 가입시점 약관·상품자료를 기준으로 한다.
2. **보험료 안내 답변 최적화** (3-1항) — 구체적 금액 답변 사례에 대한 보험료 안내 금지 규칙 적용.
3. **현재 판매 상품 답변 최적화** (2-2항 / 3-2항) — 현재 판매 상품 데이터를 1순위 기준으로 적용, 월 1회 정기 업데이트.

## 현재 판매 상품 데이터

`data/current_sales_products.csv`는 현재 판매 상품 데이터의 **예시**이다.
운영 시에는 정기 업데이트된 원본 데이터(엑셀)를 기준으로 교체한다.

컬럼: `상품명`, `기본상품명`, `개정코드`, `종_플랜_채널`, `판매상태`, `기준일`

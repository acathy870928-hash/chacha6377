# 연금설계 AI

국민연금·퇴직연금·개인연금·기타자산을 **기대수명까지 연도별로 흘려보내**
자산 고갈 시점, 소득 공백기, 세금이 튀는 지점을 찾아내는 은퇴설계 도구입니다.

배포: https://legacy-planning-ai.vercel.app

---

## 이 도구가 다른 연금계산기와 다른 점

대부분의 연금계산기는 **한 시점의 스칼라 계산**을 합니다 — "지금 얼마 모았나".
연금설계의 실제 문제는 **30~40년에 걸친 시계열**입니다 — "몇 살에 바닥나는가".

그래서 이 도구의 중심은 계산 결과가 아니라 **연도별 현금흐름 시뮬레이션**입니다.

한국 연금 구조에서 단순 합산이 놓치는 세 가지를 명시적으로 다룹니다.

| 함정 | 이 도구의 처리 |
|---|---|
| **소득 공백기** — 60세 정년, 65세 국민연금 개시 사이 5년 | 별도 지표·진단 룰로 분리해 경고 |
| **층마다 다른 물가 연동** — 국민연금은 물가연동, 주택연금은 명목 고정 | 실질가치 기준으로 계산하되 주택연금만 매년 구매력을 깎음 |
| **연 1,500만원의 벽** — 사적연금 수령액이 넘으면 저율 분리과세 종료 | 인출 순서에 반영하고, 초과 시 진단으로 경고 |

## 설계 원칙

### 1. 숫자는 룰 엔진이, 해석만 AI가

세율·공제한도·수급개시연령을 LLM이 생성하면 **그럴듯하게 틀린 숫자**가 나오고,
사용자는 그걸 믿고 30년을 계획합니다. 그래서 역할을 못 박았습니다.

- **모든 금액은 결정론적 엔진이 계산합니다** (`assets/engine.js`)
- **모든 위험 판정은 명시적 규칙이 내립니다** (`assets/rules.js`) — 같은 입력이면 언제나 같은 결과
- **AI는 이미 확정된 숫자를 읽고 해석만 합니다** (`api/advisor.js`) — 금액을 새로 만들지 않습니다

### 2. API 키가 없어도 제품의 100%가 동작한다

`ANTHROPIC_API_KEY`가 없으면 AI 브리핑 카드만 접히고, 진단·시뮬레이션·시나리오 비교는
그대로 동작합니다. AI는 부가 레이어이지 전제조건이 아닙니다.

### 3. 의존성 0개, 빌드 단계 0개

프런트엔드는 순수 ES 모듈 + 인라인 SVG입니다. 번들러도, CSS 프레임워크도,
차트 라이브러리도 쓰지 않습니다. 빌드가 깨질 지점이 구조적으로 없습니다.
`@anthropic-ai/sdk`는 선택 기능인 서버리스 함수에서만 씁니다.

### 4. 입력값은 브라우저를 떠나지 않는다

자산·가족관계는 최고 수준의 민감정보입니다. 모든 계산이 클라이언트에서 끝나고,
저장은 `localStorage`에만 합니다. AI 브리핑을 누를 때만 **계산된 지표 요약**이 전송되며,
원본 입력값은 전송되지 않습니다.

### 5. 정책값은 코드가 아니라 데이터

세율·한도·수급연령은 매년 바뀝니다. 전부 `assets/policy.js` 한 곳에 기준연도와 함께
격리해 두었습니다. 제도가 개정되면 이 파일만 갱신하면 됩니다.

## 구조

```
index.html            화면 구조
assets/
  policy.js           세율·공제한도·수급연령 (기준: 2026년) ← 개정 시 여기만 수정
  engine.js           현금흐름 시뮬레이션 엔진 (순수 함수, DOM 의존성 없음)
  rules.js            진단 룰 + 종합점수
  charts.js           인라인 SVG 렌더러 (라이브러리 없음)
  app.js              화면 조립
  styles.css          라이트/다크 테마
api/advisor.js        AI 브리핑 (선택) — 키가 없으면 503
tests/engine.test.mjs 엔진 검증 테스트
```

## 계산 모델

모든 금액은 **오늘의 화폐가치(실질)** 로 계산합니다. 명목 물가상승률은
실질수익률 변환(피셔 방정식)으로 흡수하고, 물가에 연동되지 않는 소득만 따로 깎습니다.

**적립기** (현재 나이 → 은퇴): 각 계좌를 실질수익률로 굴리고, 납입액은 실질 임금상승률로 증가시킵니다.

**인출기** (은퇴 → 기대수명): 매년 필요 생활비를 아래 순서로 조달합니다.

1. 국민연금 (연금소득공제 후 종합과세 간이 적용)
2. 주택연금 (비과세, 명목 고정 → 실질가치 하락)
3. 퇴직연금 계좌 — 이연퇴직소득 재원이므로 연 1,500만원 한도 대상이 아님
4. 개인연금 계좌 — 연 1,500만원까지 저율 분리과세(연령별 3.3~5.5%)
5. 기타 금융자산
6. 부족하면 개인연금 추가 인출 (16.5% 고율 분리과세)

어느 해에 위 재원으로 생활비를 못 채우면 그 나이가 **자산 고갈 시점**입니다.

### 종합점수 (100점)

| 항목 | 배점 | 산식 |
|---|---|---|
| 생활비 충족률 | 40 | `40 × 충족률²` — 부족액을 비선형으로 무겁게 반영 |
| 소득대체율 | 30 | `30 × (대체율/70%)^1.5` — 단, 목표 생활비를 온전히 조달하면 감점하지 않음 |
| 고갈 시점 | 20 | 고갈이 없으면 만점, 있으면 은퇴~기대수명 구간 비례 |
| 위험요인 | 10 | 위험 1건당 -5, 주의 1건당 -2 |

## 로컬 실행

빌드가 없으므로 정적 서버만 있으면 됩니다.

```bash
python3 -m http.server 8000     # http://localhost:8000
npm test                        # 엔진 검증 테스트 (23개)
```

## 배포 (Vercel)

프레임워크 감지 없이 정적 파일 + `api/` 서버리스 함수로 배포됩니다.

AI 브리핑을 켜려면 프로젝트 환경변수에 `ANTHROPIC_API_KEY`를 추가하세요.
설정하지 않아도 나머지 기능은 모두 동작합니다.

## 한계

- 세법·연금제도 값은 **2026년 기준**이며 매년 바뀝니다. 실제 적용값은 관계 법령을 확인하세요.
- 국민연금 간이추정은 가입시기별 소득대체율을 단순화한 것이라 오차가 있습니다.
  국민연금공단 '내 연금 알아보기' 조회값 입력을 권장합니다.
- 퇴직소득세는 근속연수·환산급여에 따라 크게 달라지므로 실효세율을 가정합니다.
- 주택연금 월지급금은 공시 지급률 테이블의 선형보간 추정치입니다.
- 법인 승계, 해외자산, 신탁 설계, 배우자 유족연금은 다루지 않습니다.

**이 서비스는 법률·세무·투자 자문이 아닌 참고용 시뮬레이션입니다.**

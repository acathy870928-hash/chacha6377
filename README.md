### 원문 보존 원칙
- 페이지 객체를 그대로 복사합니다. 텍스트·표·서식을 재작성하지 않습니다.
- 원본 페이지가 빠짐·겹침 없이 정확히 한 번씩 7개 파일에 나뉘는지 자동 검증합니다.
- `split_manifest.json`에 원본/결과 파일의 SHA-256과 페이지 범위를 기록해 출처를 증빙합니다.
- 별표 첫머리의 표지·목차 페이지는 기본적으로 어느 파일에도 넣지 않습니다(`--prefix-to-first`로 1번 파일에 포함 가능).

### 사용법
```bash
pip install -r requirements.txt

# 1) 제목이 어느 쪽에서 잡히는지 확인
python tools/split_standard_terms.py 원본.pdf --detect

# 2) 분할 계획(쪽 범위)만 확인
python tools/split_standard_terms.py 원본.pdf --dry-run

# 3) 분할 실행 → standard_terms/20260910/ 에 7개 PDF + split_manifest.json
python tools/split_standard_terms.py 원본.pdf -o standard_terms/20260910

# 자동 판별이 틀리면 쪽 범위를 직접 지정 (tools/ranges.example.json 참고)
python tools/split_standard_terms.py 원본.pdf -o standard_terms/20260910 --ranges ranges.json
```

시작 페이지는 각 쪽 상단 텍스트에서 약관 제목(`생명보험 표준약관`, `질병·상해보험 표준약관`,
`해외여행 실손의료보험 표준약관` 등)을 찾아 판별합니다. 공백·가운뎃점 차이는 무시하며,
여러 제목이 한꺼번에 나오는 표지·목차 쪽은 제외합니다. 원본이 스캔 이미지(텍스트 없음)이면
자동 판별이 되지 않으므로 `--ranges`로 지정해야 합니다.

# Insurance Vertical AI™

> Insurance, Augmented.
> **Protect Your If. Secure Your When.**
> *Creating the Future Standard of Insurance*

보험을 위해 태어난 AI. 범용 AI가 아니라 보험상품·보험법·보험약관·보험설계·보험소비자를 이해하는
버티컬 인텔리전스로, 보험을 **설명하는** AI가 아니라 보험의 **의사결정을 함께하는** AI를 지향합니다.

## AI 학습·주입 순서

Manifesto와 Charter는 기능·상품·데이터보다 **먼저** 학습되어야 하는 페르소나 정의입니다.

```
1. Manifesto      → 존재 이유와 세계관
2. Charter        → 행동 규범 (하한선)
3. Persona Core   → 공통 정체성·톤·금지사항
4. Persona 개별   → iFA AI / Insurance AI 역할 분화
5. 자기정의       → 1인칭 표준 답변 (정체성 질문의 고정 응답)
6. 표준 용어      → Glossary (MediCode / MIM™ 표기 고정)
7. 도메인 지식    → 상품·약관·법령·설계 데이터
```

## 용어 체계

| 레이어 | 용어 | 용도 |
| --- | --- | --- |
| 상위 개념 | **Insurance Vertical AI™** | 보험을 위해 태어난 AI |
| 내부 — 기술·철학 | **MediCode Insurance Methodology (MIM™)** | 방법론·기술 문서·AI 학습 |

> 메디코드 보험설계는 질병예측모형 기반의 AI 보험설계입니다.

## 우리가 준비하는 두 가지 미래

- **If** — 질병, 사고, 예상하지 못한 위험과 같은 고객의 '만약'
- **When** — 은퇴, 장수처럼 반드시 찾아오지만 언제인지는 알 수 없는 고객의 '언젠가'

# 법인카드 음성 입력

녹음 버튼을 누르고 말하면 **날짜·금액·사용처·계정과목·인원·사용목적**이 자동으로 채워지는 법인카드 사용내역 입력 도구입니다.
서버·회원가입·API 키가 필요 없는 정적 웹앱이라, 파일을 열기만 하면 바로 쓸 수 있고 사내 서버나 GitHub Pages에 올려 팀 전체가 쓸 수도 있습니다.

```
🎙  "어제 거래처 미팅으로 스타벅스에서 3만 2천원 3명"

    사용일자   2026-08-05   (어제 → 자동 계산)
    사용처     스타벅스
    금액       32,000원
    계정과목   접대비        ("거래처 미팅" → 자동 분류)
    인원       3명
    사용목적   거래처 미팅
```

## 바로 쓰기

```bash
npm start          # http://localhost:8080 이 열립니다
```

또는 `index.html` 파일을 크롬으로 열어도 됩니다.
(마이크는 `https://` 또는 `localhost` 에서만 동작합니다. 사내 배포 시 HTTPS 주소를 사용하세요.)

## 사용 흐름

1. **녹음 시작** 버튼을 누르고 사용 내역을 말합니다.
2. 말이 끝나면 버튼을 다시 눌러 녹음을 멈춥니다. → 폼이 자동으로 채워집니다.
3. 초록색 테두리로 표시된 항목이 음성에서 자동 인식된 값입니다. 틀린 곳만 고칩니다.
4. **저장** 을 누르면 아래 목록에 쌓입니다.
5. 월말에 **CSV 내려받기**(엑셀용) 또는 **표로 복사**(그룹웨어·엑셀 붙여넣기용)로 한 번에 제출합니다.

> 기본 설정에서 **“말하면 바로 저장”** 을 켜면 확인 단계 없이 곧바로 등록됩니다.
> 음성 인식이 지원되지 않는 브라우저에서는 문장을 직접 입력하고 **문장 분석** 을 눌러도 동일하게 동작합니다.

## 이렇게 말하면 됩니다

| 말하기 | 인식 결과 |
| --- | --- |
| `김밥천국에서 점심 9천원` | 오늘 · 김밥천국 · 9,000원 · 식대 |
| `어제 팀 회식 삼겹살 15만원 6명` | 어제 · 150,000원 · 복리후생비 · 6명 |
| `지난주 금요일 택시비 23,000원` | 지난주 금요일 · 23,000원 · 교통비 |
| `7월 21일 출장 호텔 숙박 12만원` | 2026-07-21 · 120,000원 · 숙박비 |
| `가맹점 이디야 4500원 목적은 외부 미팅 다과` | 이디야 · 4,500원 · 사용목적: 외부 미팅 다과 |

### 자동 인식 규칙

- **날짜** — 아무 말도 하지 않으면 **오늘**로 자동 설정됩니다.
  `오늘 / 어제 / 그저께`, `월요일 / 지난주 금요일`, `7월 21일`, `3/5`, `21일` 을 인식합니다.
- **금액** — `12000원`, `45,000원`, `3만 2천원`, `만원`, `오만원` 처럼 숫자·한글·혼용 모두 인식합니다.
  `3명` 같은 인원 표현은 금액으로 잡지 않습니다.
- **사용처** — `○○에서`, `가맹점 ○○`, 주요 브랜드명(스타벅스·배달의민족·GS25 등), `○○식당/카페/마트` 형태를 인식합니다.
- **계정과목** — 식대 · 접대비 · 복리후생비 · 회의비 · 교통비 · 숙박비 · 사무용품비 · 소모품비 · 통신비 · 도서인쇄비 · 교육훈련비 · 광고선전비 · 기타
  (`거래처`가 들어가면 접대비, `회식`이면 복리후생비처럼 키워드 가중치로 판단합니다.)
- **인원** — `3명`, `세 명`
- **사용목적** — `목적은 ~`, `~ 건` 을 우선 사용하고, 없으면 금액·날짜를 걷어낸 나머지 문장을 씁니다.

계정과목 이름이 회사 계정 체계와 다르면 `src/parser.js` 의 `CATEGORIES` 와 `CATEGORY_RULES` 만 고치면 됩니다.

## 데이터 보관과 내보내기

- 내역은 **사용자 브라우저(localStorage)** 에만 저장됩니다. 외부로 전송되지 않습니다.
- 브라우저 데이터를 지우면 함께 지워지므로, 제출이 끝난 달은 CSV로 내려받아 보관하세요.
- CSV는 UTF-8 BOM으로 저장되어 엑셀에서 한글이 깨지지 않습니다.
- 내보내기 열 순서: 사용일자 · 사용처 · 금액 · 계정과목 · 사용목적 · 인원 · 부서 · 사용자 · 카드 · 원본 음성
  회사 양식에 맞추려면 `src/export.js` 의 `COLUMNS` 를 수정하세요.

## 브라우저 지원

| 브라우저 | 음성 입력 | 비고 |
| --- | --- | --- |
| 크롬 / 엣지 (PC·안드로이드) | ✅ | 권장 |
| 삼성 인터넷 | ✅ | |
| 사파리 (iOS 14.5+) | ⚠️ 부분 지원 | 인식이 끊기면 직접 입력 사용 |
| 파이어폭스 | ❌ | 문장 직접 입력으로 동일하게 사용 가능 |

휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**를 하면 앱처럼 쓸 수 있습니다.

## 사내 배포

정적 파일만으로 구성되어 있어 별도 빌드가 필요 없습니다.

- **GitHub Pages** — 저장소 Settings → Pages → Source를 `main` 브랜치 `/ (root)` 로 지정
- **사내 웹서버** — 저장소 전체를 그대로 정적 경로에 복사

두 경우 모두 HTTPS여야 마이크가 동작합니다.

## 구조

```
index.html              화면
assets/style.css        스타일 (라이트/다크 자동)
src/parser.js           한국어 문장 → 지출 항목 파싱 (핵심 로직, 순수 함수)
src/speech.js           브라우저 음성 인식(Web Speech API) 래퍼
src/storage.js          localStorage 저장/조회
src/export.js           CSV · TSV 변환
src/app.js              화면 연결
tests/                  파서·내보내기 테스트
```

## 개발

```bash
npm test    # 19개 테스트 (파싱 규칙, CSV 이스케이프)
```

파싱 규칙을 바꿀 때는 `tests/parser.test.mjs` 에 사례를 먼저 추가하면 회귀를 막을 수 있습니다.

# 벨루가 검증용 상품 27선

iFA 판매실적 상품목록(199건)에서 **보험구분(생명보험/손해보험) × 보종별로 최소 1개씩** 포함되도록
27개 상품을 선정합니다. 표준약관 7개와 합쳐 30개 구성을 만들 때 나머지 자리에 해당합니다.

## 선정 기준
1. **1차 지표는 월납실적**(내림차순), 동률이면 계약건수.
2. **보종 커버리지 우선** — 생보·손보 각 보종의 실적 1위 상품을 먼저 확보합니다. 원본에 존재하는 모든 보종이 빠짐없이 들어갑니다.
3. **남은 자리는 실적순**으로 채우되, 같은 `판매사 × 보종` 조합은 1개만 넣고(유사 약관 중복 방지), 한 보종은 최대 3개까지만 넣습니다(종신·연금 편중 방지).

보종은 상품명 키워드로 분류합니다(`classify.py`). 실손·운전자·펫·치매간병·치아·자녀·재물화재·연금변액·종신·암·상해·건강종합 순으로
먼저 맞는 규칙을 적용하며, 상품명에 포함된 판매사명(예: `삼성화재`)은 규칙 적용 전에 제거해 오분류를 막습니다.

| 보종별 요약 | 보종별 전체 상품수 대비 선정 수와 선정 상품명 |

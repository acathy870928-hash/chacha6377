# 표준 태그 사전

문서 태깅에 사용할 수 있는 태그의 전체 목록이다. **여기에 있는 태그만 사용한다.**
새 태그가 필요하면 먼저 이 사전의 태그로 표현할 수 있는지 확인하고, 정말 없을 때만
`scripts/tag_rules.json`과 이 문서에 함께 추가한다.

`문서 수`는 AI 챗봇 등록 문서 14,097건(2026-08-12 기준)에 적용했을 때의 사용 건수다.
새 태그를 만들지 판단할 때 "이 정도 규모로 반복될 개념인가"를 가늠하는 기준으로 쓴다.

질병 태그는 `#건강상식`과 함께 붙어 "무엇에 대한 건강 문서인지"를 좁히는 역할을 한다.
상품군 태그와도 함께 붙는다. 암보험 자료에는 `#암보험`과 `#암`을, 치매간병보험 자료에는
`#간병보험`과 `#치매`를 같이 붙여 상품 쪽에서도 질병 쪽에서도 검색되게 한다.
질병명 태그를 새로 만들 때는 **최소 10건 이상 반복 등장하는 질병군인지** 확인한다.
한 문서에만 나오는 희귀 질환은 상위 질환군 태그(`#소화기질환`, `#호흡기질환` 등)로 흡수한다.

`#보험기초`는 다른 태그를 찾지 못했을 때의 기본값이다. 이 태그가 계속 늘어난다면
그 문서군을 설명할 구체적인 태그가 빠져 있다는 신호이므로, 해당 문서들을 훑어보고
반복되는 주제를 새 태그로 승격할지 검토한다.

## 태그 선택 시 헷갈리는 조합

| 상황 | 판단 |
| --- | --- |
| 보험상품을 다룬 교육자료 | `#설계사교육` + 해당 상품군 태그 (예: `#설계사교육` `#변액보험`) |
| 세금 관련 상담 교육 | `#설계사교육` + `#세금` (+ `#상속` 등 세부 주제) |
| 상속세·증여세 자료 | `#세금` + `#상속` 또는 `#증여` (복합 태그 만들지 않음) |
| 암보험 상품 자료 | `#암보험` + `#암` — 상품 태그와 질병 태그를 같이 붙인다. `#암`으로 검색했을 때 질병 자료와 상품 자료가 함께 나와야 하기 때문이다 |
| 치매간병보험 상품 | `#간병보험` + `#치매` |
| 자동차사고 보상 자료 | `#자동차보험` + `#보험금청구` |
| 유병자 대상 인수 기준 | `#간편보험` + `#언더라이팅` |
| 노후 대비 연금 상품 | `#연금보험` + `#노후준비` |
| 투자 관점의 퇴직연금 운용 | `#퇴직연금` + `#투자` |
| 법인 CEO 퇴직금 절세 | `#법인` + `#퇴직연금` + `#절세` |

## 태그 구조

태그는 두 층으로 쓴다. 상위 태그(`#건강상식` `#세금` `#설계사교육` `#투자` `#상품분석` `#의약품` `#보험기초`)가
문서의 큰 갈래를 잡고, 세부 태그(`#당뇨병` `#상속` `#영업화법` 등)가 그 안에서 무엇인지를 좁힌다.
그래서 두 층이 함께 붙는 것은 중복이 아니라 의도된 구조이며, 검토 리포트도 이 조합을
"통합 대상 아님"으로 따로 분리해 보여준다.

## 통합 권장에 대한 판단

리포트 5번 항목은 기계적으로 뽑은 후보다. 실제 적용 여부는 아래와 같이 판단했다.

| 후보 | 판단 | 이유 |
| --- | --- | --- |
| `#상속` `#증여` `#양도소득세` → `#세금` | **통합하지 않음** | 세무 문서가 783건으로 가장 큰 덩어리다. 여기서 상속·증여·양도를 구분하지 못하면 `#세금` 하나로는 검색이 사실상 불가능해진다. |
| 질병 태그 → `#건강상식` | **통합하지 않음** | 건강 문서 1,661건이 `#건강상식` 하나만 공유하면 태그가 있으나 마나다. 질병 태그는 모두 13건 이상 반복 사용되므로 재사용 조건을 충족한다. |
| `#영업화법` → `#설계사교육` | **통합하지 않음** | 교육 과정이 아닌 화법·판매 전략 단독 자료가 따로 있다. |
| `#암` ↔ `#암보험`, `#치매` ↔ `#간병보험` | **둘 다 붙임** | 상품 태그와 질병 태그는 역할이 달라 같은 문서에 함께 붙인다. 암보험 자료 145건 중 144건에 `#암`이 함께 붙어, `#암`으로 검색하면 질병 자료와 상품 자료가 모두 나온다. |
| `#주택연금` → `#부동산` | **유지하되 관찰** | 34건 전부 `#부동산`과 함께 붙었다. 문서가 더 늘지 않으면 다음 검토 때 `#부동산` + `#노후준비`로 흡수 가능. |
| `#시책` (3건) | **유지** | 저빈도지만 시책·프로모션 자료는 주기적으로 등록되는 성격이라 앞으로 재사용될 태그다. |
| `#보험기초` (530건) | **유지하되 관찰** | 다른 태그를 찾지 못했을 때의 기본값이다. 이 안에서 반복되는 주제가 보이면 새 태그로 승격한다. |

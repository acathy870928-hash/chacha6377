# UI 시안 작업 파일

insurance AI 모바일 앱 UI 시안의 원본입니다.
각 `.dc.html`이 캔버스의 한 화면(아트보드)이고, `canvas.json`이 배치와 메모를 담습니다.

| 파일 | 화면 | 보여주는 결정 |
| --- | --- | --- |
| `Main.dc.html` | 첫 화면 | **팔지 않는다** — 상품 배너 대신 질문 입력창이 주인공 |
| `Scan.dc.html` | 약관 넣기 | 부가 기능이 아니라 **주 동선** |
| `Answer.dc.html` | 답변 | 결론 먼저, 근거는 조항으로, **불리한 것도 먼저** |
| `Unknown.dc.html` | 모른다 | 실패가 아닌 화면 |
| `Diagnosis.dc.html` | If·When 진단 | 두 축을 함께 보는 구조 |
| `MediCode.dc.html` | 메디코드 인계 | 왜 기준이 필요한지 → 유료 전환 |

## 디자인 체계

브랜드 문서와 같은 값을 씁니다.

| | |
| --- | --- |
| 잉크 | `#1B2A2E` |
| 지면 | `#F5F6F4` · 카드 `#FFFFFF` |
| If (만약) | `#0E6E70` · 배경 `#E8F1F0` |
| When (언젠가) | `#9A6128` · 배경 `#F5EDE3` |
| 표제 | Gowun Batang |
| 본문·UI | IBM Plex Sans KR |

- 화면 크기 390×844 (모바일)
- 터치 영역 최소 44px
- 아이콘은 인라인 SVG만 사용 (이모지 금지)
- 상태바·키보드는 그리지 않습니다 (실기기에서 겹칩니다)

## 표기 주의

브랜드는 **`insurance AI`** — 소문자 insurance + 대문자 AI. 문장 첫머리에도 대문자로 바꾸지 않습니다.
디자인 툴의 자동 대문자화와 CSS `text-transform`을 꺼야 합니다.

## 시안 내용에 관한 참고

- 숫자와 상품 내용은 시안용 예시입니다
- 메디코드 가격은 `[금액]` 자리로 비워두었습니다
- 정적 시안입니다 (버튼 동작 없음)

## 배포

`insurance-ai-ui.html`은 작업 파일에서 생성되는 배포 파일이라 버전 관리하지 않습니다.
화면을 고칠 때는 `.dc.html`을 고치고 캔버스를 다시 만들어 같은 링크로 갱신합니다.

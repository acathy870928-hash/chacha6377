# 주간 업무 보고 — 차승희 2

- **기간**: 2026년 8월 4주차 (2026. 8. 4W)
- **작성자**: 차승희
- **주요 협업**: 배서현M, 엄범식M, 최보민M, 벨루가

---

## A. ORCA AI / iFA AI 답변 품질 QA 진행 (with 배서현M)

### 1. 실손보험 데이터 검색 개선

- 실손보험 관련 자료가 있음에도 일부 질문에서 해당 자료를 찾지 못하고 답변하지 못하는 사례 확인
- 기존 데이터가 RAG 검색에 적합하지 않은 형태로 구성되어 있던 것이 주요 원인으로 확인
- 엄범식M이 실손보험 관련 데이터를 RAG 검색에 적합한 형태로 정비 및 업로드
- 데이터 정비 후 재테스트 결과, 검색 및 답변 성능이 정상적으로 개선된 것을 확인

> **상태**: 완료

### 2. 미답변 질문 데이터 보완

- 우주보험 관련 질문 등 일부 영역에서 관련 자료 부족으로 답변하지 못하는 사례 확인
- 관련 자료 확인 후 추가 업로드하여 데이터 보완
- 향후 QA 과정에서 발생하는 미답변 질문을 지속적으로 확인하여 필요한 데이터 보완 예정

> **상태**: 진행 중 (상시)

### 3. 보험료 안내 답변 최적화

- 보험료 관련 질문에서 보험료가 구체적인 금액으로 답변되는 사례 확인
- AI가 보험료를 안내하지 않도록 **보험료 안내 금지 규칙** 적용 필요
- 관련 개선사항은 벨루가 R&R 범위로 취합하여 일괄 적용 요청 예정

> **상태**: 요청 예정 (벨루가 R&R)

### 4. 현재 판매 상품 답변 최적화

- 현재 판매 중인 보험상품을 묻는 질문에, 과거 판매종료 상품까지 현재 판매 상품처럼 답변하는 문제 확인
- 개선방법으로 현재 판매 상품 데이터 수집 완료(엄범식M), 최신성 유지를 위해 **월 1회 정기 업데이트** 예정
- 현재 판매 상품 데이터를 우선 기준으로 답변하도록 별도 규칙 적용 필요
- 관련 개선사항은 벨루가 R&R 범위로 취합하여 일괄 적용 요청 예정

> **상태**: 데이터 수집 완료 / 규칙 적용 요청 예정 (벨루가 R&R)

### 5. 상충 정보 확인을 위한 ERP 화면 요청

- 서로 상충되는 정보가 검색되는 경우 답변 정확도에 영향을 줄 수 있다는 안내 문구가 노출되는 사례 확인
- 현재 안내 문구만으로는 어떤 정보가 서로 상충되는지 확인하기 어려움
- 상충되는 정보의 내용과 출처를 확인할 수 있도록 **관리자 ERP 화면** 필요
- 답변 근거자료 표시 기능은 이전 회의에서 요청한 사항으로, 최보민M이 8/24 벨루가에 요청사항 전달

> **상태**: 요청 전달 완료 (8/24, 최보민M → 벨루가)

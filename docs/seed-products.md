# 초기 등록 대상 (손해보험)

`data/products_nonlife.csv` — 손해보험 실적 기준 상품 목록 (91개 상품, 61,297건).
회사 · 종별 · 상품명 · 건수 · 월납보험료로 구성된다.

초기 100건을 무엇으로 채울지 추측하지 않고 이 데이터로 정한다.
보상 질문은 계약이 있는 곳에서 나오므로 건수가 많은 상품이 먼저다.

## 계약 커버리지

| 상위 N개 상품 | 덮는 계약 비율 |
| --- | --- |
| 10개 | 42.7% |
| 20개 | 59.1% |
| 30개 | 71.0% |
| 40개 | 80.0% |
| 50개 | 86.2% |
| 60개 | 91.2% |
| 91개 (전체) | 100% |

상위 30개면 계약의 7할, 50개면 8할 이상을 덮는다. 뒤쪽은 효율이 급격히 떨어진다.

## 「약관 100건」은 상품 100개가 아니다

같은 상품도 **보장형태 · 납입방법 · 개정 판**에 따라 약관 파일이 갈린다.
(모홈 화면에서 「동행」 하나가 6개 이상으로 나뉘던 것과 같다.)

따라서 약관 예산 100건을 상품 수로 환산해야 한다.

| 상품당 약관 수 가정 | 담을 수 있는 상품 | 계약 커버리지 |
| --- | --- | --- |
| 1건 | 91개 (전체) | 100% |
| 2건 | 50개 | 86.2% |
| 3건 | 33개 | 74.1% |
| 4건 | 25개 | 65.4% |

**벤더에서 실제 약관 목록을 받아 이 배수를 확인해야 계획이 확정된다.**
지금은 2.0을 기본값으로 두었다(`registration_plan(terms_per_product=...)`).

배수가 3~4로 나오면 커버리지가 크게 떨어지므로, 그때는
「보장형태 · 납입방법 전부」가 아니라 **건수가 몰린 조합만 골라 넣는 것**이 낫다.

| 종별 | 상품 수 | 건수 |

| 운전자 | 9 | 21,981 |
| 건강보험 | 26 | 21,325 |
| 실손의료 | 4 | 2,835 |
| 재물·화재·가정 | 3 | 2,181 |
| 어린이·자녀 | 3 | 1,930 |
| 종합보험 | 2 | 1,256 |
| 암보험 | 2 | 779 |
| 치매·간병 | 1 | 537 |

**운전자보험이 상품 9개로 건수 1위다.** 상위 10개 중 7개가 운전자보험이다.
보상 문의가 많은 상품군(벌금 · 형사합의금 · 자동차사고부상치료비 등)과 겹치므로
이 데이터가 보상 질문 대비에 잘 맞는다.

건강보험은 상품 수가 26개로 흩어져 있다. 회사마다 간편심사 상품을 여러 개
운영하기 때문이다. 상품당 건수는 적지만 합치면 운전자와 비슷하다.

## 이 데이터로 확인된 것

**1. 상품명 표기가 실제로 흔들린다.**
정규화(`normalize_product_name`)를 적용해 같은 회사 안에서 검사하면
서로 포함 관계인 상품이 4쌍 나온다. 되묻기가 필요한 실제 사례다.

```
[삼성화재] 건강보험 New내돈내삼         ↔  무배당 삼성화재 건강보험 New내돈내삼1640
[삼성화재] (무)삼성화재간편365알뜰한새로고침100세 ↔ (무)삼성화재 간편365 알뜰한 새로고침
[한화손보] 한화 더 경증 간편건강보혐II(세만기형) ↔ 한화 더 경증 간편건강보혐
[한화손보] 한화 시그니처 여성 간편건강보험 4.0(무) ↔ 한화 시그니처 여성 간편건강보험(무)
```

FA가 「내돈내삼」이라고만 말하면 두 상품 중 어느 쪽인지 알 수 없다.
이름이 정확히 일치해도 시리즈가 있으면 되묻는 규칙이 실제로 필요하다는 근거다.

**2. 원천 데이터에 오타가 있다.**
「한화 더 경증 간편건강보혐」 — 보험이 아니라 **보혐**으로 들어와 있다.
실적 데이터의 상품명과 벤더 인덱스 · 공시실 표기가 정확히 일치하지 않을 수 있다는 뜻이다.
`CatalogEntry.aliases`로 흡수해야 한다.

**3. 배당 표기가 제각각이다.**
`(무)`, `무배당`, `(무배당)`, 접미 `(무)` 등이 섞여 있다.
정규화가 이 부분을 걷어내므로 `make_product_id()`는 표기가 달라도 같은 ID를 만든다.

## 아직 없는 것

- **생명보험 상품 목록** — 이 파일은 손해보험만 담고 있다.
- **약관 판(시행일) 정보** — 이 데이터에는 없다. 벤더 또는 공시실에서 받아야
  가입 시점 → 판 특정이 동작한다. 지금은 상품 목록만 있는 상태다.
- **과거 판매 종료 상품** — 이 목록은 최근 실적 기준이라 현재 판매 상품 중심이다.
  보상 질문은 과거 계약에서도 나오므로, 판매 종료 상품은 요청을 받아 채우게 된다.
  초기 미등록 비율이 높게 나올 수 있으니 지표로 지켜봐야 한다.

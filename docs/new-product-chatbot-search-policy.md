# 신상품 기반 상품 검색·안내 정책 (인슈어런스 챗봇 요건)

- 수신: 벨루가
- 작성: 상품/서비스 담당
- 상태: 협의 요청 (Draft)

---

## 1. 배경

현재 사내에 **별도로 정리·관리되는 "신상품 목록"** 이 존재합니다.
인슈어런스 챗봇이 상품을 검색하고 안내할 때, 전체 상품 카탈로그(과거 상품 포함)를
그대로 대상으로 삼으면 이미 판매하지 않거나 현행 정책과 맞지 않는 상품이
안내될 위험이 있습니다.

따라서 **챗봇의 기본 검색 범위를 신상품 카테고리로 한정**하는 것을 요건으로 정리합니다.

## 2. 핵심 요구사항

### 2-1. 기본 동작 (Default)

> 사용자가 **특정 과거 시점(또는 과거 상품)을 명시하지 않는 한**,
> 챗봇은 **신상품 목록으로 정리된 카테고리 안에서만** 상품을 검색하고 안내한다.

- 상품 추천, 상품 비교, "무슨 보험 있어요?" 류의 일반 질의 → 전부 신상품 목록 범위 내에서 응답
- 신상품 목록 밖의 상품은 기본 응답 후보에서 제외

### 2-2. 예외 (전체 카탈로그로 확장하는 조건)

아래 중 하나에 해당할 때만 과거 상품을 포함한 전체 범위로 검색을 확장한다.

| 구분 | 사용자 발화 예시 | 검색 범위 |
|---|---|---|
| 시점 명시 | "2021년에 나온 상품", "작년에 판매하던 거", "예전 상품 중에" | 전체(과거 포함) |
| 기간 명시 | "2019~2020년 사이 상품" | 해당 기간 |
| 상품 특정 | 신상품 목록에 없는 상품명·상품코드를 직접 지목 | 해당 상품 단건 |
| 보유계약 문의 | "내가 가입한 상품" (본인 계약 조회 연동 시) | 계약 기준 |

- 위 조건에 해당하지 않는 모든 경우는 **2-1 기본 동작**을 따른다.
- "최신", "요즘", "새로 나온" 등의 표현은 시점 명시가 아니라 **기본 동작 강화**로 해석한다.

### 2-3. 응답 규칙

1. 신상품 범위에서 결과가 없을 때는 임의로 과거 상품으로 확장하지 않는다.
   → "현재 안내 가능한 신상품 중에는 해당 조건에 맞는 상품이 없습니다.
      과거 상품까지 확인해 드릴까요?" 형태로 **되묻고 사용자가 동의한 경우에만** 확장.
2. 과거 상품을 안내하는 경우 **"현재 판매 중이 아닌 상품"** 임을 응답에 명시한다.
3. 안내 문구에는 상품명 + 판매개시일(또는 신상품 기준일)을 함께 노출해
   사용자가 시점을 판단할 수 있게 한다.
4. 최종 가입 조건·보장 내용은 약관/상품설명서를 근거로 안내하고 링크를 함께 제공한다.

## 3. 신상품 목록 연동 사양 (협의 필요)

챗봇이 참조할 신상품 목록의 최소 필드 제안입니다.

| 필드 | 설명 | 필수 |
|---|---|---|
| product_code | 상품코드 (고유 식별자) | O |
| product_name | 상품명 | O |
| category | 상품 유형/카테고리 (예: 건강, 상해, 저축) | O |
| launch_date | 판매개시일 | O |
| sales_status | 판매상태 (판매중 / 판매중지) | O |
| summary | 상품 한 줄 요약 (챗봇 안내용) | O |
| target | 가입 대상·연령 등 주요 조건 | △ |
| doc_url | 약관·상품설명서 링크 | △ |
| updated_at | 목록 갱신 일시 | O |

- 신상품 여부는 **자동 기간 계산(예: 최근 N개월)이 아니라, 우리가 관리하는 목록 자체를 단일 기준(SSOT)** 으로 한다.
- 목록에서 제외되면 챗봇 기본 검색 대상에서도 즉시 제외되어야 한다.

## 4. 벨루가 회신 요청 사항

1. 신상품 목록 전달 방식: **API 연동 / 파일(엑셀·CSV) 정기 업로드 / 관리자 화면 등록** 중 어느 쪽이 적합한지
2. 목록 갱신 주기와 챗봇 반영까지의 소요 시간 (실시간 / 일 배치 등)
3. 사용자 발화에서 "과거 시점 언급"을 판별하는 로직을 챗봇 측에서 처리 가능한지, 가능하다면 정확도 수준
4. 검색 범위 확장 시 되묻기(2-3-1) 플로우 구현 가능 여부
5. 판매중지 상품에 대한 안내 문구 정책 (노출 여부 포함)
6. 위 3장 필드 스펙 중 추가·조정이 필요한 항목

## 5. 미정 사항 (내부 확정 필요)

- 신상품 목록에 포함할 상품의 선정 기준·주기
- 판매중지된 신상품의 목록 잔존 여부
- 계약 조회 연동 범위 (2-2의 "보유계약 문의" 예외 적용 여부)

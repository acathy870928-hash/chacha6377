# 06. Business Model

## 💰 1. 초기 수익원

| 수익원 | 설명 |
|--------|------|
| **AI 구독 (AI SaaS Subscription)** | 보험소비자·설계사·GA 대상 AI 서비스 구독 |
| **Enterprise License** | 보험회사·GA 등 기업 단위 라이선스 |
| **보험회사 광고** | 플랫폼 내 보험회사 광고 |
| **AI 상담요청 DB** | AI 상담을 통해 발생한 상담요청 데이터 |
| **White Label** | 파트너 브랜드로 제공하는 화이트라벨 서비스 |
| **MCP / API 사용료** | 외부 시스템 연동을 위한 MCP·API 사용료 |

---

## 2. 궁극적인 수익원

### AI Commerce

**보험계약 체결에 따른 수수료(Commission)가 iFA AI & Co.의 궁극적인 핵심 수익원이 됩니다.**

- Insurance Vertical Agentic AI를 통한 보험계약 수수료
- Marketplace 수수료

---

## 수익 구조의 진화

```
AI 구독 · Enterprise License · 광고 · API
              ↓
      (Agentic AI 고도화)
              ↓
   AI Commerce — 보험계약 수수료 · Marketplace 수수료
```

초기에는 **AI 서비스 제공에 따른 이용료**를 중심으로 수익을 창출하고,
Insurance Vertical Agentic AI가 고객의 보험 여정(분석 → 비교 → 추천 → 가입 → 유지관리 → 연금 → 상속)을
직접 수행하게 되면서 **AI Commerce**가 핵심 수익원으로 전환됩니다.

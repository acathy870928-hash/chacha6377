## 1. 실손의료보험 개편 (5세대 실손)

| 항목 | 내용 |
|---|---|
| 출시 | 2026년 5월 6일 |
| 보장 구조 | 급여 + 중증 비급여(특약1) 강화 / 비필수·과잉 비급여(특약2) 억제 |
| 보험료 | 4세대 대비 약 30%, 1·2세대 대비 50% 이상 인하 |
| 제한 대상 | 도수치료, 체외충격파 등 남용 우려 비급여 |
| 강화 대상 | 암, 희귀난치성 질환 등 중증 질환 |
| 전환 할인 | 1·2세대 대상 선택형 할인 특약·계약전환 할인 → 2026년 11월부터 3년간 50% 할인 |
| 전환 기간 | 2026년 7월 ~ 2036년 6월, 10년간 순차 전환 |

> **확인 필요** — "5월 6일 출시"와 "7월부터 10년 순차 전환"은 각각 다른 기사에 나온 표현입니다.
> 상품 출시일과 기존 계약 전환 개시일이 다른 것으로 보이나, 금융위 보도자료로 확정하세요.

지적이 이어지고 있습니다.

## 2. 판매수수료 제도 개편

단계별로 시행 중입니다.

| 시기 | 내용 |
|---|---|
| 2026년 3월 | 판매수수료 **비교공시** 제도 시행 |
| 2026년 7월 1일 | GA 소속 설계사에게 **1200%룰** 확대 적용 (7/1 체결 계약부터) |
| 2026년 7월 1일 | 대형 GA(설계사 500명 이상) **비교·설명 의무** 도입 |
| 2027년 1월 | 판매수수료 **분급제** 시행 예정 |

- **1200%룰** — 초년도 모집수수료 지급 한도를 월납 보험료의 12배로 제한.
  기존에는 보험사 → 전속설계사·GA 지급분에만 적용됐고, GA → 소속 설계사 지급분은 제외였음.
  (월납 10만원이면 첫해 수수료 상한 120만원)
- **비교·설명 의무** — 유사 상품군의 판매수수료 등급·순위·추천 사유를 설명해야 하며,
  비교설명 확인서에 평균 대비 수수료 수준을 '매우 높음 ~ 매우 낮음' **5단계**로 표시.
- **분급제** — 수수료를 장기간 나눠 지급. 단기 수수료 경쟁 대신 계약 유지·관리로 유도하려는 취지.

- [금융위 보도자료 — 보험 판매수수료 개편 방안](https://www.fsc.go.kr/no010101/84721)
- [보험신보 — GA 설계사도 1200%룰 적용](https://www.insweek.co.kr/news/articleView.html?idxno=71554)
- [뉴스핌 — 보험 판매수수료 1200%룰, 7월부터 GA 설계사에도 적용](https://www.newspim.com/news/view/20260630000586)

## 3. 건전성 규제 — 기본자본 지급여력비율

금융위는 2026년 1월 15일 **보험업법 시행령·보험업감독규정 개정안**을 입법예고·규정변경예고했습니다.

개정안의 세 축:

1. 5세대 실손보험 **상품설계기준** 규정
2. **기본자본 지급여력비율** 도입 — 자본의 양뿐 아니라 질도 함께 규제
3. **판매채널 책임성** 강화

절차는 입법예고 → 규제개혁위원회·법제처 심사 → 차관회의·국무회의 의결 순이며,
**2026년 상반기 중 개정 완료** 예정으로 발표됐습니다.

관련해 IFRS17 계리적 가정 가이드라인, 무·저해지 상품 해지율 가정 정비도 함께 진행 중입니다.

## 4. 자동차보험

- **8주 룰** — 상해등급 12~14급 경상환자가 8주를 넘겨 치료받는 경우
  보험금 지급에 별도 심의를 거치도록 함. 기존 4주 관리 체계를 강화한 것.
- 보험연구원이 **자기부담금 제도** 개선 방안을 검토 중.
- 금융당국은 실손 + 자동차보험을 두 축으로 하는 '민생 보험개혁'을 예고.

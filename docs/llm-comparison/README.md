# 챗봇 대 범용 LLM 비교, 내부 검토용 체크리스트

우리 보험 상담 챗봇(문서 검색 기반)과 범용 LLM에 같은 질문을 던지고
답을 비교하는 내부 검토를 위한 최소 가이드.

## 꼭 지킬 것

- 실제 고객 정보는 범용 LLM 입력창에 넣지 않는다. 질문은 가상 인물로 만든다.
- 범용 LLM 답을 정답으로 보지 않는다. 헷갈리면 약관을 연다.
- 범용 LLM이 시원하게 답한 상품 추천은 우리가 하면 안 되는 답일 수 있다.
  그 경우 우리 챗봇의 회피가 정답이다.

## 하면 좋은 것

- 범용 LLM은 새 대화, 메모리 끔, 웹 검색 끔 상태로 시작한다.
- 질문 문구는 두 쪽에 똑같이 복사해 넣는다.
- 우리 챗봇이 틀린 문항은 검색해 온 문서 조각을 같이 본다.
  못 찾은 건지, 찾고도 틀린 건지가 갈린다.
- 결과는 아래 표 하나로 정리한다.

| 번호 | 질문 | 우리 답 요약 | 범용 답 요약 | 맞음/틀림/회피 | 메모 |
|---|---|---|---|---|---|
| | | | | | |

## 질문 예시 (가상 인물, 가상 계약)

**우리 문서에 답이 있는 질문**
1. 실손의료보험에서 도수치료는 연간 몇 회까지 보장되나요?
2. 암 진단비 특약은 진단 확정일 기준인가요, 청구일 기준인가요?
3. 보험금 청구 시 필요한 서류는 무엇인가요?

**개인 가입 내역이 있어야 답할 수 있는 질문**
4. 제가 가입한 보험에서 무릎 관절경 수술이 보장되나요?
5. 지금 내는 보험료를 줄일 수 있는 방법이 있나요?

**최근 바뀐 제도나 세법 질문**
6. 올해 기준으로 자녀에게 증여할 때 비과세 한도가 얼마인가요?
7. 실손보험 세대 전환을 하면 무엇이 달라지나요?

**상담사 연결이 필요한 상황**
8. 보험금 지급이 거절됐는데 어떻게 이의를 제기하나요?
9. 부모님 사망 후 보험금 상속 절차가 궁금합니다.

**범위 밖 질문**
10. 오늘 서울 날씨 어때요?

각 문항의 정답 근거(약관 조항이나 공시자료)는 실행 전에 적어 둔다.

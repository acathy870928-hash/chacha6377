# 아이에프에이 에이아이(IFA AI) 사업자등록 가이드

AI 서비스/솔루션 사업을 "아이에프에이 에이아이" 상호로 개시할 때의 사업자등록 절차 정리입니다.

> ⚠️ 아래 내용은 일반적인 절차 안내입니다. 세액감면·업종코드·간이과세 판정 등은 개별 사정에 따라 달라지므로,
> 최종 확정 전 **관할 세무서(국번없이 126)** 또는 세무대리인에게 확인하세요.

---

## 0. 한눈에 보는 흐름

### 개인사업자로 시작하는 경우

```
상호·사업장 결정 → 홈택스 사업자등록 신청 → (2일 내) 사업자등록증 발급
   → 사업용 계좌·카드 등록 → 통신판매업 신고(필요 시) → 4대보험(직원 채용 시)
```

### 법인(주식회사)으로 시작하는 경우

```
상호 중복 확인 → 정관 작성 → 자본금 납입·잔고증명 → 법인설립등기(등기소)
   → 법인등기부등본 발급 → 사업자등록 신청 → 법인 통장 개설 → 이후 개인과 동일
```

법인은 **설립등기가 먼저**입니다. 등기 없이는 사업자등록을 할 수 없습니다.

## 1. 개인 vs 법인 결정

| 항목 | 개인사업자 | 법인사업자(주식회사) |
|---|---|---|
| 설립 절차 | 사업자등록만 (무료, 2일) | 설립등기 필요 (등록면허세·법무 비용, 1~2주) |
| 세율 | 종합소득세 6~45% 누진 | 법인세 9~24% (과세표준 2억 이하 9%) |
| 이익 인출 | 자유 (인출 자체는 과세 없음) | 급여·배당으로만 (별도 과세) |
| 대외 신용 | 상대적으로 낮음 | 투자 유치·B2B 계약·정부지원 사업에 유리 |
| 책임 범위 | 무한책임 | 출자액 한도 유한책임 |
| 간이과세 | 가능 (요건 충족 시) | 불가 (항상 일반과세) |
| 4대보험 | 대표는 지역가입(직장가입 아님) | 대표도 직장가입자 |

**AI 사업 관점의 판단 기준**

- 초기 매출이 작고 1인 또는 소수로 검증 단계 → **개인사업자**로 시작 후 법인 전환
- VC·엑셀러레이터 투자 유치, 정부 R&D 과제, 대기업 B2B 계약, 스톡옵션 부여 계획 → 처음부터 **법인**
- SaaS/API 형태로 기업 고객에게 세금계산서를 끊어야 한다면 법인 쪽이 거래상 매끄럽습니다.

## 2. 신청 기한·비용·처리 기간

| 항목 | 내용 |
|---|---|
| 신청 기한 | 사업 개시일로부터 **20일 이내** (부가가치세법 제8조). 개시 전 신청도 가능 |
| 신청처 | 홈택스 온라인 또는 **전국 아무 세무서** 민원봉사실 (관할 아니어도 접수 가능) |
| 수수료 | 무료 |
| 처리 기간 | 통상 **2일**(토·공휴일 제외). 현장확인 대상이면 최대 5일 이상 |

**지연 시 불이익**

- 미등록가산세: 공급가액의 1%
- 등록 전 매입세액 불공제 (다만 **개시일이 속한 과세기간 종료 후 20일 이내** 등록하면 그 기간의 매입세액은 소급 공제 가능)

→ 사무실 보증금, 장비, GPU 클라우드 비용 등 초기 매입이 크다면 **지출 전에 등록**하는 것이 유리합니다.

## 3. 사업장 소재지

| 형태 | 필요 서류 | 주의사항 |
|---|---|---|
| 임차 사무실 | 임대차계약서 사본 | 계약서상 주소와 신청 주소가 일치해야 함 |
| 자택 (본인 소유) | 별도 서류 불필요 | 실제 업무 수행 사실 확인 요청 가능 |
| 자택 (가족 소유/전세) | 무상사용승낙서 + 소유자 신분 확인 서류 | 세무서 서식 사용 |
| 공유오피스 | 입주 계약서 / 사용확인서 | 비상주(주소지만 대여) 상품은 **현장확인·등록 거부** 사례가 있으니 사전 문의 필수 |

소프트웨어 개발업은 별도 인허가가 필요 없어 자택 사업장으로도 무리 없이 등록됩니다.

## 4. 업태·종목(업종코드) 선택

AI 사업은 **정보통신업**으로 잡는 것이 일반적입니다.

**주업종 후보**

| 업태 | 종목 | 비고 |
|---|---|---|
| 정보통신업 | 응용 소프트웨어 개발 및 공급업 | AI 솔루션·SaaS·앱의 표준 선택 |
| 정보통신업 | 컴퓨터 프로그래밍 서비스업 | 수탁 개발(SI·외주) 위주일 때 |
| 정보통신업 | 포털 및 기타 인터넷 정보매개 서비스업 | 웹 서비스·플랫폼 운영 |
| 정보통신업 | 데이터베이스 및 온라인정보 제공업 | 데이터·API 판매 |
| 전문·과학·기술 서비스업 | 기타 공학 연구개발업 | R&D 과제 수행 목적 병기 시 |

**부업종으로 함께 등록해두면 좋은 것**

- 광고 대행/온라인 광고업 (AI 마케팅 서비스를 겸할 경우)
- 경영컨설팅업 (AI 도입 컨설팅 매출)
- 전자상거래 소매업 (온라인으로 직접 결제받아 판매할 경우)

> 업종코드 번호는 개정되므로 신청 직전에 확인하세요.
> **홈택스 → 상담·불복·고충·제보·기타 → 기타 → 기준(단순)경비율·업종코드 조회**에서 키워드로 검색할 수 있습니다.

업종코드는 경비율·간이과세 배제 여부·창업 세액감면 대상 판정에 직접 영향을 주므로, **실제 매출이 나오는 활동**으로 정확히 잡아야 합니다. 부업종은 여러 개 등록 가능하고 나중에 정정 신고로 추가·변경할 수 있습니다.

## 5. 과세유형 (일반 vs 간이)

- **법인은 선택권 없이 일반과세자**입니다.
- 개인사업자는 직전 연도 공급대가가 기준 금액(2024.7.1. 이후 개시분 기준 1억 400만 원) 미만이면 간이과세 적용 가능하나, 신규 사업자는 예상 매출로 판단합니다.

**AI 사업은 일반과세자가 유리한 경우가 많습니다.**

- 고객이 기업(B2B)이면 세금계산서 발급이 사실상 필수인데, 간이과세자는 발급에 제약이 있습니다.
- GPU 클라우드·API 사용료·장비 구입 등 초기 매입세액이 크면 일반과세자만 전액 환급받을 수 있습니다.
- 해외 매출(수출)은 영세율 대상이라 일반과세자가 매입세액을 환급받는 구조가 유리합니다.

간이과세를 원하지 않으면 신청서에 **"간이과세 포기"**를 함께 체크합니다.

## 6. 필요 서류

### 개인사업자

- [ ] 사업자등록 신청서 (홈택스 온라인 작성 또는 세무서 서식)
- [ ] 대표자 신분증
- [ ] 임대차계약서 사본 (사업장 임차 시)
- [ ] 무상사용승낙서 (가족 명의 주택 등을 사업장으로 쓸 때)
- [ ] 동업계약서 (2인 이상 공동사업 시)
- [ ] 인허가증 사본 (해당 업종만 — AI 소프트웨어 개발업은 통상 불필요)

### 법인사업자

- [ ] 법인설립신고 및 사업자등록 신청서
- [ ] 법인등기부등본 (법인등기사항전부증명서)
- [ ] 정관 사본
- [ ] 주주 또는 출자자명세서
- [ ] 임대차계약서 사본 (사업장 임차 시)
- [ ] 대표이사 신분증, 법인 인감증명서 및 인감도장
- [ ] 현물출자명세서 (현물출자가 있는 경우)

## 7. 홈택스 온라인 신청 경로

1. [홈택스](https://www.hometax.go.kr) 로그인 (공동인증서 / 금융인증서 / 간편인증)
2. **국세증명·사업자등록·세금관련 신청/신고 → 사업자등록 신청·정정·휴폐업 → 사업자등록 신청(개인)** 
   (법인은 **사업자등록 신청(법인)**)
3. 인적사항 → 사업장 정보 → 업종 선택 → 사업장 정보 추가 입력 → 과세유형 선택
4. 증빙서류 파일 첨부 (임대차계약서 등, PDF·JPG)
5. 신청 후 **My홈택스 → 민원신청 처리결과 조회**에서 진행 상태 확인
6. 발급되면 홈택스에서 사업자등록증 즉시 출력 가능

모바일 손택스 앱으로도 동일하게 신청할 수 있습니다.

## 8. 등록 직후 반드시 할 일

| 순서 | 항목 | 내용 |
|---|---|---|
| 1 | 사업용 계좌 개설·신고 | 사업자등록증 지참하여 은행 방문 → 홈택스에 사업용 계좌 신고 (복식부기의무자는 의무, 미신고 시 가산세) |
| 2 | 사업용 신용카드 등록 | 홈택스에 등록하면 매입세액공제·경비 처리가 자동 집계됨 |
| 3 | 전자세금계산서 발급 준비 | 홈택스 또는 발급 대행 서비스. 법인은 전자발급 의무 |
| 4 | 현금영수증 가맹 | B2C 매출이 있으면 가입 |
| 5 | 통신판매업 신고 | 온라인에서 직접 결제받아 판매하면 관할 시·군·구청 신고 (구매안전서비스 이용확인증 필요) |
| 6 | 4대보험 성립신고 | 직원 채용 시 14일 이내 |
| 7 | 개인정보 처리 준비 | 이용자 데이터를 다루는 AI 서비스는 개인정보처리방침 게시, 위탁·국외이전 고지 의무 확인 |

## 9. AI 스타트업이 챙길 만한 세제 혜택·제도

- **창업중소기업 세액감면** — 요건 충족 시 5년간 소득세·법인세 50~100% 감면. 청년(만 34세 이하) 창업, 수도권 과밀억제권역 외 창업 여부에 따라 감면율이 달라집니다. 정보통신업은 대상 업종에 포함됩니다.
- **연구·인력개발비 세액공제** — AI 모델 개발 인건비를 R&D 비용으로 인정받을 수 있습니다. **기업부설연구소 / 연구개발전담부서** 인정(한국산업기술진흥협회)을 받아두면 인정 범위가 넓어집니다.
- **벤처기업 확인** — 벤처확인종합관리시스템. 법인세·취득세 감면, 정부 지원사업 가점.
- **창업기업 확인(창업 7년 이내)** — K-스타트업 지원사업 지원 자격의 기본 요건.

이런 혜택은 **업종코드와 창업일 기준으로 판정**되므로, 사업자등록 단계에서 업종을 잘못 잡으면 사후에 감면을 못 받는 경우가 생깁니다.

## 11. 상호 "아이에프에이 에이아이" 관련 확인 사항

- **법인 설립 시** — 대법원 [인터넷등기소](https://www.iros.go.kr) 법인상호검색에서 동일 관할 내 동일 상호가 있는지 확인해야 합니다. 개인사업자는 상호 중복 제한이 없습니다.
- **영문 표기** — 정관·등기에 영문 상호(예: IFA AI Inc. / IFA AI Co., Ltd.)를 함께 등재해두면 해외 계약·결제 서비스 가입 시 편합니다.
- **상표 출원** — 사업자등록 상호는 상표권과 무관합니다. 서비스명을 브랜드로 쓸 계획이면 [특허정보넷 키프리스](https://www.kipris.or.kr)에서 선등록 상표를 확인하고 별도 출원하세요. AI 서비스는 제9류(소프트웨어)·제42류(SaaS·컴퓨터 서비스업)가 주 지정상품류입니다.
- **도메인** — 상호 확정 전에 도메인·소셜 핸들 가용 여부를 함께 확인하는 편이 좋습니다.

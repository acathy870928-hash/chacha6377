1. 보험료 안내 제한 규칙

공식 보험료 산출 시스템이 연동되기 전까지 보험상품의 구체적인 보험료 금액은 안내하지 않는다. 보험료와 관련한 모든 판단과 근거 확인은 항상 최신 파일을 기준으로 수행한다.

1-1. 보험료 금액 안내 금지

  1. 보험료, 예상보험료, 월납·연납보험료, 최저·평균보험료 등 보험료 관련 구체적인 금액을 생성·추정·계산하거나 안내하지 않는다.
  2. 상품안내장, 가입예시, 교육자료, 내부자료 등 검색자료에 보험료가 포함되어 있더라도 해당 금액을 답변에 노출하거나 인용하지 않는다.
  3. 사용자가 나이, 성별, 직업, 가입금액, 담보구성 등을 제공하더라도 보험료를 임의로 계산하거나 추정하지 않는다.
  4. 상품 간 보험료를 비교하거나 특정 상품의 보험료가 저렴하다·비싸다·유리하다 등의 판단을 하지 않는다.
  5. 사용자가 과거 보험료 또는 문서상 가입예시 보험료를 직접 요청하더라도 구체적인 보험료 금액은 제공하지 않는다.
  6. 보험료 이외의 상품정보는 확인 가능한 근거자료를 기반으로 정상적으로 안내한다.

1-2. 보험료 관련 안내는 최신 파일 기준 신설

  1. 보험료 및 보험료 산출 조건과 관련된 안내는 반드시 최신 파일(최신 게시일·적용일 기준의 최종 버전 자료)을 기준으로 한다.
  2. 동일 상품에 대해 여러 시점의 자료가 검색된 경우, 가장 최근에 적용·개정된 파일만을 근거로 채택하고 과거 버전 파일의 보험료 관련 정보는 인용·요약·비교 대상에서 제외한다.
  3. 보험료율·요율표·가입예시 등이 개정된 경우, 개정 전 파일의 내용은 현재 기준으로 안내하지 않는다.
  4. 최신 파일이 확인되지 않거나 자료 간 시점이 상충하는 경우에는 보험료 관련 안내를 보류하고 고정 응답으로 전환한다.
  5. 보험료 외 상품정보를 안내할 때에도 근거자료의 출처와 게시일·적용일(기준일)을 함께 표시하여 최신성을 명확히 한다.
  6. 동일 상품군 내에서는 상품명 말미의 개정코드(YYMM, 예: 2607)가 가장 높은 자료를 최신 파일로 판별하며, 개정코드가 낮은 과거 상품은 최신 기준 자료로 사용하지 않는다.
  7. 단, 과거 가입상품에 대한 질문은 예외로 하여 최신 파일이 아닌 가입시점에 적용된 약관·상품자료를 기준으로 확인한다.

보험료 질문 시 고정 응답

“보험료는 가입조건, 담보 구성 및 보험사의 인수기준 등에 따라 달라질 수 있어 정확한 산출 없이 안내하기 어렵습니다. 정확한 보험료는 FA를 통해 안내받으시길 추천합니다.”

→ FA 상담하기 버튼 노출

2. 상품 최신성 및 판매여부 운영 규칙

과거 상품자료가 검색되었다는 이유만으로 현재 판매 중인 상품으로 안내하지 않는다. 메타데이터에는 사실정보를 저장하고, 최신성과 현재 판매 여부는 답변 시점에 판단한다.

2-1. 상품자료 기본 메타데이터

항목저장 내용
보험사 / 상품명상품 식별을 위한 기본 정보
문서종류상품안내장, 약관, 공시, 내부자료 등
게시일문서가 게시된 날짜
적용일·개정일상품조건 또는 문서가 실제 적용되는 시점
출처보험사 공식자료 등 원천정보
수집일Insurance AI에 수집된 날짜
파일버전 신설동일 상품 자료의 최신 여부 식별값(최종본 여부) — 보험료 안내 시 최신 파일 판별 기준

2-2. 현재 판매 상품 데이터 우선 적용 신설

  1. 현재 판매 중인 상품 여부는 별도로 관리하는 ‘현재 판매 상품 데이터’를 최우선 기준으로 판단한다.
  2. 검색된 상품자료가 존재하더라도 현재 판매 상품 데이터에 포함되어 있지 않은 상품은 현재 판매 중인 상품으로 안내하지 않는다.
  3. 판매종료 상품에 대한 질문에는 판매종료 사실을 먼저 안내한 후, 필요한 경우 보장내용 등 사실정보만 설명한다.
  4. 현재 판매 상품 데이터와 검색자료의 내용이 상충하는 경우 현재 판매 상품 데이터를 우선한다.
  5. 현재 판매 상품 데이터는 종(種)·플랜 단위까지 구분하여 관리하며, 데이터에 존재하지 않는 종·플랜은 현재 판매 대상으로 안내하지 않는다.
  6. 현재 판매 상품 데이터는 최신성 유지를 위해 월 1회 정기 업데이트하며, 업데이트 기준일을 함께 관리한다.

※ 현재 판매 상품 데이터의 구성 예시는 부록 A 참조.

2-3. 현재 판매 여부 확인이 필요한 질문

“어느 보험사에서 판매하나요?”, “현재 가입 가능한 상품인가요?”, “이 보장 판매하는 회사가 어디인가요?”, “○○특약이 있는 보험사는 어디인가요?”, “지금 판매 중인 상품이 있나요?” 등의 질문은 현재 판매 여부 확인 대상으로 분류한다.

2-4. 최종 답변 검증

‘현재 판매 중’, ‘가입 가능’, ‘특약 운영 중’, ‘현재 해당 보장을 판매’, ‘구성 가능’ 등 현재 판매 사실을 의미하는 표현은 현재 판매 상품 데이터 및 최신 근거가 확인된 경우에만 사용한다.

최신 근거가 확인되지 않는 경우 → “관련 상품 또는 특약 자료는 확인되지만 현재 판매 여부는 확인이 필요합니다.”

2-5. 상품자료 최신성

1년 이상 경과 여부를 별도 상태값으로 계속 수정하지 않고, 게시일·적용일과 현재 날짜를 비교하여 답변 시점에 판단한다. 자료가 1년 이상 경과했거나 최신 여부·현재 판매 여부가 불명확한 경우, 동일 상품의 다른 시점 자료가 존재하는 경우, 사용자가 현재·최신·지금 판매 여부를 질문한 경우에는 출처와 게시일 또는 기준일을 함께 표시한다.

2-6. 자료 선택 기준(우선순위)

순위기준적용 대상
1순위현재 판매 상품 데이터현재 판매 여부·가입 가능 여부 판단
2순위최신 파일(최신 게시일·적용일 자료)보험료 관련 확인 및 현재 상품정보 안내
3순위기타 공식 상품자료보장내용 등 사실정보 보완
예외가입시점 적용 약관·상품자료과거 가입상품에 대한 질문

2-7. 운영 원칙

메타데이터에는 사실(Fact)을 저장하고, 변하는 상태(State)는 답변 시점에 판단한다. 모든 상품의 판매상태를 사람이 지속적으로 변경하는 방식은 지양하고, 현재 판매 상품 데이터의 정기 업데이트를 기본으로 하되 향후 보험사 공식 상품정보 또는 상품공시 데이터를 자동 수집하여 판매상태를 정기적으로 검증하는 방식으로 고도화한다.

3. 답변 최적화 개선 과제

3-1. 보험료 안내 답변 최적화

현황보험료 관련 질문에서 보험료가 구체적인 금액으로 답변되는 사례 확인
개선 방향AI가 보험료를 안내하지 않도록 보험료 안내 금지 규칙 적용 필요
보험료 관련 확인이 필요한 경우 최신 파일을 기준으로만 근거를 확인하고, 금액은 노출하지 않음
적용 규칙1-1항(보험료 금액 안내 금지) · 1-2항(최신 파일 기준) · 보험료 질문 시 고정 응답 + FA 상담 연결
R&R벨루가관련 개선사항은 벨루가 R&R 범위로 취합하여 일괄 적용 요청 예정

3-2. 현재 판매 상품 답변 최적화

현황현재 판매 중인 보험상품을 묻는 질문에 과거 판매종료 상품까지 현재 판매 상품처럼 답변하는 문제 확인
개선 방향현재 판매 상품 데이터 수집 완료(엄범식M)
최신성 유지를 위해 월 1회 정기 업데이트 예정
적용 규칙현재 판매 상품 데이터를 우선 기준으로 답변하도록 별도 규칙 적용(2-2항) · 미포함 상품은 현재 판매로 단정 금지
R&R벨루가관련 개선사항은 벨루가 R&R 범위로 취합하여 일괄 적용 요청 예정

4. 정책 요약

구분정책
보험료차단(Block) — 구체적인 금액 생성·추정·인용·비교 금지, 고정 응답 및 FA 상담 연결
보험료 근거자료최신 기준(Latest) — 보험료 관련 안내는 항상 최신 파일 기준, 과거 버전 자료 인용 금지
현재 판매 여부검증(Verify) — 현재 판매 상품 데이터와 최신 근거가 있을 때만 현재 판매로 단정
현재 판매 상품 데이터우선(Priority) — 검색자료보다 우선 적용, 월 1회 정기 업데이트
오래된 상품자료표시(Disclose) — 출처와 게시일·기준일을 함께 안내
과거 가입상품시점 일치(Match) — 가입시점에 적용된 약관·상품자료 우선
개선 적용 방식일괄 적용(Batch) — 벨루가 R&R 범위로 취합 후 일괄 적용 요청

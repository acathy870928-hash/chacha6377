# 아이에프에이 에이아이 사업자등록 체크리스트

진행하면서 하나씩 체크하세요. 상세 설명은 [사업자등록-가이드.md](./사업자등록-가이드.md) 참고.

## 1단계 — 결정 사항

- [ ] 개인사업자 / 법인 중 선택
- [ ] 상호 확정: 아이에프에이 에이아이 (영문: IFA AI)
- [ ] 사업 개시일 확정 (등록 기한 = 개시일 + 20일)
- [ ] 사업장 주소 확정 (자택 / 임차 / 공유오피스)
- [ ] 주업종·부업종 확정 (홈택스 업종코드 조회로 번호 확인)
- [ ] 과세유형 결정 (일반과세 권장 / 간이과세 포기 여부)
- [ ] 공동사업 여부 및 지분율 (해당 시)

## 2단계 — 법인인 경우에만 (개인은 건너뜀)

- [ ] 인터넷등기소에서 동일 상호 검색
- [ ] 자본금·주주 구성 확정
- [ ] 정관 작성
- [ ] 자본금 납입 및 잔고증명서 발급
- [ ] 설립등기 신청 (등록면허세·지방교육세 납부)
- [ ] 법인등기부등본·법인 인감증명서 발급

## 3단계 — 서류 준비

- [ ] 대표자 신분증
- [ ] 임대차계약서 사본 (임차 시)
- [ ] 무상사용승낙서 (가족 명의 사업장 사용 시)
- [ ] 동업계약서 (공동사업 시)
- [ ] 법인: 정관 사본, 주주명세서, 등기부등본

## 4단계 — 신청

- [ ] 홈택스 로그인 (공동/금융인증서 또는 간편인증)
- [ ] 사업자등록 신청서 작성 및 서류 첨부
- [ ] 신청 접수 완료
- [ ] 처리 결과 확인 (통상 2일)
- [ ] 사업자등록증 출력·보관

## 5단계 — 등록 직후

- [ ] 사업용 계좌 개설
- [ ] 홈택스에 사업용 계좌 신고
- [ ] 홈택스에 사업용 신용카드 등록
- [ ] 전자세금계산서 발급 환경 준비
- [ ] 현금영수증 가맹 (B2C 매출 시)
- [ ] 통신판매업 신고 (온라인 직접 판매 시)
- [ ] 4대보험 성립신고 (직원 채용 시)
- [ ] 개인정보처리방침 작성·게시

## 6단계 — 놓치기 쉬운 것

- [ ] 창업중소기업 세액감면 대상 여부 검토
- [ ] 청년창업 감면 요건(만 34세 이하) 해당 여부
- [ ] 연구개발전담부서 설립 검토
- [ ] 벤처기업 확인 신청 검토
- [ ] 상표 출원 (제9류·제42류) 검토
- [ ] 첫 부가가치세 신고 기한 캘린더 등록

## 이슈 1. 연관질문이 보험과 무관한 주제로 생성되는 현상

### 현상 (9/1 확인)
질의 "강아지가 무지개다리를 건너면 펫보험에서 보상이 되나요?" → 답변은 정상. 이후 연관질문 3건이 모두 보험과 무관:
- 무지개 다리 전설은 어디서 유래했나요?
- 무지개 다리 전설이 현대 문화에 미친 영향은?
- 무지개 다리 전설이 반려동물 문화에 주는 의미는?

사용자는 AI가 제시한 연관질문을 "답변 가능한 질문"으로 인식하므로, 클릭 후 답변 실패로 이어지면 서비스 신뢰도에 직접 영향.

### 원인 추정
- 연관질문 생성이 **사용자 질문 텍스트(또는 답변 텍스트)만** 입력으로 받아 LLM이 자유 생성 → 문장 속 화제어("무지개다리")에 끌려감.
- 답변에 실제 사용된 **검색 문서(근거 청크)와 채널 서비스 범위**가 생성 프롬프트에 들어가지 않음.
- 생성된 후보를 **걸러내는 검증 단계가 없음** → 답변 불가능한 질문이 그대로 노출.

### 개선 요청 (이렇게 고쳐 주세요)
1. **생성 입력을 바꿔 주세요.** 연관질문 생성 시 답변에 사용된 검색 청크(출처 문서)를 함께 넣고, "이 문서들로 답할 수 있는 질문만 생성"하도록 제약. 사용자 질문의 비유·감성 표현(무지개다리, 하늘나라 등)은 화제로 삼지 않도록 지시.
2. **채널별 서비스 범위를 프롬프트에 명시해 주세요.** (범위 정의는 iFA 제공)
   - ORCA(설계사용): 상품·약관·보상·청약/유지·영업지원·관련 법령
   - iFA AI(고객용): 본인 보장 내용·청구·계약 관리·일반 보험 상식
   - Insurance AI(대외용): 일반 보험 지식 (내부 영업 정보 제외)
   - 범위 밖 주제(문화·역사·어원·시사 등)는 생성 금지.
3. **생성 후 검증 게이트를 넣어 주세요.** 후보 질문 각각을 검색기로 다시 조회해 관련 문서 점수가 기준 미만이면 제외(자기 검증). 또는 경량 분류기로 "보험 관련 + 답변 가능" 판정. 통과 건이 부족하면 **미노출**(기존 합의 규격 "3~5개, 실패 시 미노출, 응답 지연 없음" 준용).
4. **질문 확장 방향 규칙.** 후속 질문은 사용자 의도 축으로만 확장. 예) 펫보험 보상 → 보상 조건·청구 서류·면책 사항·가입 가능 연령·보장 한도.
5. **Trace 반영.** 연관질문 클릭으로 들어온 질의에 플래그를 남겨, 연관질문 경유 답변 실패율을 모니터링.

### iFA 준비 사항
- 채널별 서비스 범위 정의서 1장 (허용 주제 / 금지 주제 예시)
- 좋은 연관질문 · 나쁜 연관질문 예시 각 10건
- 테스트셋 30건 (비유·감성 표현, 고유명사, 다의어 포함) + 판정 기준: "생성된 연관질문 100%가 채널 범위 내이며 실제 답변 가능"

### 벨루가 확인 사항
- 현재 연관질문 생성 방식 (입력이 무엇인지, 답변 전/후 어느 시점인지, 검색 근거를 참조하는지)
- 생성 후 검증 단계 추가 시 응답 지연 영향

## 이슈 2. 교육자료·소식지 내 보험료 수치 노출

### 현상
교육자료·소식지 일부에 보험료가 구체 수치로 기재 → 답변에 그대로 인용될 가능성. 해당 데이터는 iFA에서 삭제 진행 중이며, 별도 보험료 데이터셋 구축 전까지 구체 금액이 노출되지 않도록 관리 예정. 보험료 안내 문구·제한 기준은 iFA에서 보강.

### 원인 추정
- 보험료 질의도 일반 질의와 동일하게 벡터 검색 → 교육자료·소식지 청크 속 금액이 근거로 채택됨.
- 보험료처럼 **조건(보험사·상품·담보·연령·가입금액)에 따라 값이 달라지는 정형 데이터**를 비정형 문서 검색으로 다루고 있어, 조건 불일치 금액이 답변될 수 있음.

### 개선 요청 (이렇게 고쳐 주세요)

**A. 즉시 조치 (데이터셋 구축 전 임시 가드레일)**
1. 보험료 질의(보험료·월납·얼마·비용·납입액 등) 감지 시 **구체 금액을 제시하지 않고** iFA 제공 안내 문구로 응답.
2. 삭제·재색인이 끝나기 전까지 교육자료·소식지 청크의 **금액 표현을 답변에 인용하지 않도록** 프롬프트 제약 + 응답 후처리(금액 패턴 마스킹) 병행.

**B. 본 조치 (보험료 전용 데이터 지정)**
1. iFA가 제공하는 보험료 Excel을 **벡터 청킹 대상이 아니라 정형 테이블 조회 소스**로 다뤄 주세요.
2. 질의 처리 흐름:
   - 보험료 의도 분류 → 조건 추출(보험사 / 상품명 / 담보명 / 성별 / 연령 / 가입금액 / 납입·보험기간) → Excel 테이블 조회 → **조회 결과만으로 답변**.
   - 조건이 부족하면 되묻기(예: "연령과 가입금액을 알려주세요").
   - 조회 결과가 없으면 "해당 조건의 보험료 데이터가 없다"고 안내하고, **다른 문서에서 추정하지 않음**.
3. **소스 우선순위 고정.** 보험료 질의에서는 Excel만 근거로 사용. 교육자료·소식지는 보험료 근거로 사용 금지.
4. 답변에 **기준일자(데이터 버전)** 표시. 예) "2026-09 기준 보험료".

**C. API 전환·병행 (향후)**
1. 보험료 조회 로직을 **도구(Tool) 형태로 분리**해 두면, 데이터 소스가 Excel → API로 바뀌어도 조회 어댑터만 교체하면 됨. 처음부터 이 구조로 설계 요청.
2. 병행 시: **API 우선 조회, 실패·타임아웃 시 Excel 폴백** 권고.
3. API 규격 초안(iFA 시스템 제공 예정): 요청 = 보험사코드·상품코드·담보코드·성별·연령·가입금액·납입기간, 응답 = 월보험료·기준일자·판매여부. 실시간 조회 가능 여부·응답 시간 요건은 벨루가 의견 필요.

### 회의에서 결정할 항목 (객관식)
- 보험료 데이터 소스 운영 방식: ① Excel 단독 ② API 단독 ③ **API 우선 + Excel 폴백 병행 (권고)**
- Excel 갱신 주기: ① 월 1회 ② 변경 시마다 ③ 분기 1회

### iFA 준비 사항
- 보험료 Excel 스키마 확정 (컬럼: 보험사 / 상품 정식명칭 / 상품코드 / 담보명 / 성별 / 연령(또는 연령대) / 가입금액 / 납입기간 / 보험기간 / 월보험료 / 기준일자 / 판매여부)
  - **상품명·보험사 표기는 이슈 3의 판매상품 마스터와 동일한 키를 사용** (두 데이터가 연결되어야 함)
- 보험료 안내 문구(임시 가드레일용) 및 제한 기준
- 갱신 주기·담당자, 보험료 질의 테스트셋 20건 (조회 성공 10 / 조건 부족 5 / 데이터 없음 5)

### 벨루가 확인 사항
- 정형 데이터(테이블) 조회를 벡터 검색과 분리해서 지원 가능한지, 믹키 업로드 시 "정형 소스"로 지정 가능한지
- 질의 의도 분류 단계가 현재 파이프라인에 있는지
- API 연동 시 지원 방식(REST/JSON 등)과 실시간 조회 가능 여부

## 이슈 3. 상품 질의 시 판매종료 상품이 함께 검색되는 현상

### 현상
신규 제안·추천·비교 등 **현재 판매상품 기준으로 답해야 하는 질의**에도 판매종료 상품이 검색되어 현행 상품 안내에 오용될 가능성. 반면 보유계약 약관 해석, 특정 가입 시점의 과거 상품 조회는 **판매종료 상품 포함 전체 검색**이 필요.

### 현재 상황 (데이터 제약)
- 색인 문서에 판매 시점·판매 여부 메타데이터 없음.
- iFA 제공 가능 자료: 현재 판매상품 마스터(Excel: 보험사 / 상품명 / 약 [ ]종). 판매종료일 데이터는 없음.
- 따라서 "마스터에 포함 = 현재 판매중, 미포함 = 판매종료"로 판정 가능.
- 현재 판매상품 요약서는 믹키에 업로드 예정 (별도 청킹 요청 없음).

### 개선 요청 (이렇게 고쳐 주세요)
1. **문서 단위 판매중 태그 부여.** 색인된 상품 문서(요약서·약관 등)의 상품명을 마스터와 매칭해 `판매중 / 판매종료` 메타데이터 부여.
   - 매칭 규칙: 상품명 정규화(공백·특수문자·괄호·"무배당/(무)" 표기·개정 버전 표기 제거) + 보험사명 조합 키 + 유사도 매칭.
   - 자동 매칭이 애매한 건은 **검수 리스트로 iFA에 전달** → iFA가 확정.
   - 상품명이 없거나 여러 상품을 다루는 문서(교육자료·소식지 등)는 `상품 해당 없음`으로 두고 필터 대상에서 제외.
2. **질의 유형 분류 후 검색 범위 분리.**
   - (가) 현행 판매 기준 질의: 추천·제안·비교·신규 가입·"요즘/현재/지금" → `판매중` 문서만 검색 (또는 판매중 우선 + 종료 상품 라벨).
   - (나) 보유계약·과거 질의: "가입한/보유/내 계약/증권/약관 해석", 특정 연도·시점 명시 → 전체 검색.
   - (다) 판단 불가: 전체 검색하되 답변에 판매종료 표시.
   - 분류는 규칙(키워드) + LLM 의도 분류 혼합 권고.
3. **답변 표시 규칙(전 채널).** 판매종료 상품을 인용할 때는 "※ 현재 판매 중이지 않은 상품" 라벨 필수. 추천·비교 답변에서는 종료 상품 제외.
4. **마스터 갱신 자동화.** 마스터 Excel 재업로드 시 태그 자동 재계산. 재계산 후 **정합성 리포트** 반환: (a) 마스터에는 있으나 문서가 없는 상품, (b) 문서는 있으나 마스터에 없는 상품 → iFA 검수.
5. **판매종료일 대체.** 마스터 업로드 이력(일자별 포함 여부)을 벨루가가 보관하면 "어느 시점부터 종료"의 근사값 확보 가능. 향후 "2025년 가입 상품" 같은 시점 질의에 활용.
6. **믹키 업로드 파일명 규칙으로 메타데이터 확보.** 별도 청킹 없이도 파일명·폴더 규칙만으로 보험사·상품명·판매여부를 읽을 수 있음. 예) `[판매중]_보험사_상품정식명칭_요약서_202609.pdf`. 벨루가가 파일명을 파싱해 태그를 부여할 수 있는지 확인 요청.

### 회의에서 결정할 항목 (객관식)
- 판매종료 상품 처리 방식: ① 추천·비교 질의에서 완전 제외 ② 항상 포함하되 "판매종료" 라벨 ③ **추천·비교는 제외, 그 외는 포함 + 라벨 (권고)**
- 질의 유형 판단 불가 시 기본값: ① 판매중만 ② **전체 검색 + 라벨 (권고)**

### iFA 준비 사항
- 현재 판매상품 마스터 Excel (보험사 / 상품 정식명칭 / 상품코드(있으면) / 생·손보 구분 / 기준일자)
- 상품명 별칭·약칭 목록 (문서 표기와 마스터 표기가 다른 사례)
- 매칭 애매 건 검수 (벨루가 리스트 수령 후)
- 믹키 업로드 파일명 규칙 확정 및 요약서 업로드
- 질의 유형 테스트셋 50건 (현행 20 / 보유·과거 20 / 모호 10) + 판정 기준: "추천·비교 답변에 판매종료 상품 0건, 보유계약 질의는 종료 상품 정상 조회"

### 벨루가 확인 사항

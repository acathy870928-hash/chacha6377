여섯 가지 설계 규칙

화면 요소 하나하나가 아래 규칙에서 나옵니다. 규칙이 바뀌면 화면도 바뀌어야 합니다.

R1되묻기는 걸러낸 뒤에만

약관이 필요한 질문 + 상품 미특정일 때만 묻는다. 개념 질문, 판이 하나뿐인 상품, 세션에 남은 상품은 묻지 않는다.

R2고르게 하고, 치게 하지 않는다

상품명 자유 입력은 표기가 흔들려 검색이 깨진다. 후보는 항상 칩으로 제시한다. 많으면 보험사부터.

R3준비중 상품도 보여준다

약관이 없어도 상품명은 목록에 나온다. 골라도 헛걸음이 아니라 등록 요청으로 이어진다.

R4임의로 판을 고르지 않는다

가입 시점이 확정되지 않으면 최신 판으로 답하지 않는다. 일반론일 때는 일반론임을 밝힌다.

R5지급사유와 면책은 한 쌍

「나오나요」에 지급사유만 보여주면 면책에 걸리는 건을 나온다고 오해하게 만든다. 항상 함께 제시한다.

R6접수는 즉시, 알림은 검수 후

요청 즉시 접수를 확인해 주고, 원 질문으로 재검증이 통과한 뒤에만 등록 완료를 알린다.

대화 플로우

다섯 장면이면 전체 상태 기계가 다 나옵니다. 초록 번호가 화면과 설명을 잇습니다.

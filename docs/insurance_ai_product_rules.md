# 1. 문서 개요

## 1-1. 목적

본 문서는 Insurance AI(챗봇/상담 어시스턴트)가 보험상품 관련 질문에 답변할 때 준수해야 하는 자료 기준과 답변 규칙을 정의한다. v1.1에서는 **보험료 안내 시 최신 파일 기준 적용**과 **현재 판매 상품 데이터 우선 적용**을 핵심 개정 사항으로 신설한다.

## 1-3. 보험료 안내 최신성 원칙 (신설)

보험료와 관련된 모든 안내·근거 확인은 **반드시 최신 파일을 기준으로 한다.**

| 조항 | 내용 |
| --- | --- |
| 7 | 보험료 관련 안내 및 근거 확인은 반드시 **최신 파일(최신 게시일·최신 적용일)** 을 기준으로 수행한다. |
| 8 | 동일 상품에 대해 서로 다른 시점의 자료가 검색된 경우, **최신 개정본만 채택**하고 과거 버전은 인용·비교 대상에서 제외한다. |
| 9 | 동일 상품군의 최신 여부는 상품명 말미의 **개정코드(YYMM, 예: `2607`)** 로 판별하며, 개정코드가 동일한 경우 파일의 게시일·적용일이 늦은 자료를 최신으로 본다. |
| 10 | 최신 파일이 확인되지 않거나 자료 간 적용 시점이 상충하는 경우, **보험료 안내를 보류하고 5장의 고정 응답으로 전환**한다. |
| 11 | 답변 시 근거 자료의 **기준 시점(적용일 또는 개정코드)** 을 함께 표기하여 사용자가 최신성을 확인할 수 있도록 한다. |
| 12 | **예외** — 과거 가입 상품에 대한 질문은 최신 파일이 아니라 **가입시점의 약관·상품자료**를 기준으로 답변한다. |

# 2. 자료 기준 규칙

## 2-1. 자료 출처 원칙

- 사내 공식 등록 자료(약관, 상품요약서, 상품설명서, 사업방법서, 판매자료)만 근거로 사용한다.
- 비공식 자료(외부 블로그, 커뮤니티, 설계사 개인 자료, 과거 캡처 이미지)는 근거로 사용하지 않는다.
- 근거 문서를 특정할 수 없는 내용은 생성하지 않는다.

## 2-2. 현재 판매 상품 데이터 우선 적용 (신설)

| 조항 | 내용 |
| --- | --- |
| 1 | **현재 판매 상품 데이터**를 상품 판매 여부 판단의 **1순위 기준**으로 사용한다. |
| 2 | 현재 판매 상품 데이터에 포함되지 않은 상품은 **'현재 판매 중'으로 안내하지 않는다.** |
| 3 | 판매종료 상품에 대한 질문에는 **판매종료 사실을 우선 안내**하고, 필요 시 현재 판매 중인 후속 상품을 별도로 안내한다. |
| 4 | 상품은 **종·플랜·채널 단위까지 구분**하여 관리한다(예: 10종 / CM / TM / 기본플랜). 동일 기본상품명이라도 데이터에 없는 종·플랜은 판매 중으로 안내하지 않는다. |
| 5 | 데이터 수집은 완료(담당: 엄범식M)되었으며, 최신성 유지를 위해 **월 1회 정기 업데이트**한다. |

## 2-3. 최신 파일 판별 기준

1. 상품명 말미 **개정코드(YYMM)** 비교 — 값이 클수록 최신 (예: `2607` > `2601`).
2. 개정코드가 동일하면 **적용일** 이 늦은 자료를 최신으로 본다.
3. 적용일이 동일하면 **게시일(등록일)** 이 늦은 자료를 최신으로 본다.
4. 위 3단계로도 판별되지 않으면 **최신성 미확인**으로 처리한다(2-5 적용).

## 2-4. 예외 처리 — 과거 가입 상품

- 사용자가 **이미 가입한 상품**에 대해 묻는 경우, 최신 개정본이 아니라 **가입시점 자료**를 기준으로 답변한다.
- 이 경우 답변에 "가입시점(YYYY.MM) 약관 기준"임을 명시한다.
- 가입시점을 확인할 수 없으면 시점을 먼저 확인하고, 확인 전에는 단정적으로 답변하지 않는다.

## 2-5. 최신성 미확인 시 처리

- 최신 파일을 특정할 수 없는 경우 **추정하여 답변하지 않는다.**
- 보험료 관련 항목은 안내를 보류하고 5장의 고정 응답으로 전환한다.
- 보험료 외 항목은 "최신 자료 확인이 필요한 사항"임을 밝히고 담당자 확인을 안내한다.

## 2-6. 자료 선택 우선순위

| 순위 | 기준 자료 | 적용 대상 |
| --- | --- | --- |
| 1 | 현재 판매 상품 데이터 | 판매 여부, 현재 판매 상품 목록, 종·플랜·채널 구분 |
| 2 | 최신 파일(최신 개정본) | 보장내용, 가입조건, 보험료 관련 근거 확인 |
| 3 | 기타 공식 등록 자료 | 1·2순위로 확인되지 않는 보조 정보 |
| 예외 | 가입시점 자료 | 사용자가 이미 가입한 상품에 대한 질문 |

# 3. 답변 최적화 규칙

## 3-1. 보험료 안내 답변 최적화

| 구분 | 내용 |
| --- | --- |
| 현황 | 보험료 관련 질문에서 보험료가 **구체적인 금액으로 답변되는 사례** 확인 |
| 개선 | AI가 보험료를 안내하지 않도록 **보험료 안내 금지 규칙** 적용 필요 |
| R&R | 관련 개선사항은 **벨루가 R&R 범위**로 취합하여 일괄 적용 요청 예정 |

### 적용 규칙

- 보험료를 **구체적 금액(원 단위, 예시 보험료, 월납/연납 금액, 예상 보험료)** 으로 제시하지 않는다.
- 보험료 산출·비교·시뮬레이션을 수행하지 않는다.
- 보험료는 **연령·성별·가입금액·특약 구성·건강상태 등에 따라 달라진다**는 점을 안내하고, 정확한 보험료는 **설계 프로그램 또는 담당 설계사**를 통해 확인하도록 유도한다.
- 보험료 산출 구조·납입 방법·갱신 주기 등 **금액이 아닌 제도적 설명**은 안내할 수 있으며, 이때에도 **최신 파일(1-3항)** 을 근거로 한다.

## 3-2. 현재 판매 상품 답변 최적화

| 구분 | 내용 |
| --- | --- |
| 현황 | 현재 판매 중인 보험상품을 묻는 질문에 **과거 판매종료 상품까지 현재 판매 상품처럼 답변**하는 문제 확인 |
| 개선 | 현재 판매 상품 데이터 수집 완료(엄범식M), 최신성 유지를 위해 **월 1회 정기 업데이트** 예정 |
| 규칙 | 현재 판매 상품 데이터를 **우선 기준**으로 답변하도록 별도 규칙 적용 필요 |
| R&R | 관련 개선사항은 **벨루가 R&R 범위**로 취합하여 일괄 적용 요청 예정 |

### 적용 규칙

- "현재 판매 중인 상품" 질문에는 **현재 판매 상품 데이터에 등재된 상품만** 제시한다.
- 데이터에 없는 상품은 판매 여부를 단정하지 않고, **판매종료 또는 확인 필요**로 안내한다.
- 상품명은 **개정코드와 종·플랜·채널을 포함한 정식 명칭**으로 표기한다.
- 과거 판매 상품을 설명해야 하는 경우 **"판매종료 상품"** 임을 문장 앞부분에 명시한다.

# 4. 운영 및 갱신 체계

| 항목 | 내용 |
| --- | --- |
| 현재 판매 상품 데이터 갱신 | 월 1회 정기 업데이트 (담당: 엄범식M) |
| 최신 파일 반영 | 신규 개정본 등록 시 즉시 반영, 과거 버전은 검색 대상에서 제외 또는 후순위 처리 |
| 개선사항 처리 경로 | 벨루가 R&R 범위로 취합 → 일괄 적용 요청 |
| 규칙 문서 관리 | 개정 시 버전·일자·개정 내용을 1-2 개정 이력에 기록 |

# 5. 고정 응답 문구

## 5-1. 보험료 관련 질문

> 보험료는 연령, 성별, 가입금액, 특약 구성 등에 따라 달라져 정확한 금액을 안내해 드리기 어렵습니다. 정확한 보험료는 설계 프로그램 또는 담당 설계사를 통해 확인해 주시기 바랍니다.

## 5-2. 최신 파일 미확인 시

> 해당 내용은 최신 자료 확인이 필요하여 현재 안내가 어렵습니다. 담당자를 통해 최신 기준으로 확인해 주시기 바랍니다.

## 5-3. 현재 판매 상품 데이터 미등재 상품

> 문의하신 상품은 현재 판매 상품 목록에서 확인되지 않습니다. 판매종료 상품이거나 별도 확인이 필요한 상품일 수 있어, 담당자를 통해 확인해 주시기 바랍니다.

# 인슈어런스 AI 기능 요청서 (벨루가 전달용)

- 문서 버전: v0.1 (2026-09-01)
- 작성 목적: 사내 인슈어런스 AI에 ①보험료 조회 ②신상품 문서 기반 답변 ③연관질문 노출 규칙을 추가 요청
- 적용 범위: 사내 상담·설계 지원용(대고객 청약 화면 아님)

---

## 0. 한 줄 요약

1. **보험료**: 사용자가 "나이 + 담보"를 말하면, 우리가 구축한 **보험료셋 데이터**로 보험료를 계산해 답한다. 이때 **담보 설명**과 **나이(보험나이) 설명**을 함께 붙인다.
2. **신상품**: 신상품 질문은 **최신 상품 리스트에 있는 상품의 문서만 담은 인덱스**에서만 검색해 답한다. 사용자가 **시점을 말하지 않으면 무조건 최신 상품 기준**으로만 답한다.
3. **연관질문**: 답변마다 3개를 노출하되, **최신 상품 범위로만 답한 경우 3개 중 1개는 반드시 "전체 문서(과거·단종 상품 포함) 검색"으로 넘어가는 질문**을 넣는다.

## 1. 기능 A — 나이·담보 기반 보험료 조회

### 1.1 동작 시나리오

```
사용자: 40세 남자 암진단비 3천만원 얼마야?

AI:
[보험료]  월 12,600원 (20년납 / 80세만기 / 비갱신)

[산출 근거]
  · 담보: 암진단비(유사암 제외) / 가입금액 3,000만원
  · 적용 요율: 남성 40~44세 구간, 1,000만원당 월 4,200원
  · 계산: 4,200원 × 3.0(가입금액 배수) × 1.00(20년납) × 1.00(80세만기) = 12,600원

[담보 설명]
  암(유사암 제외)으로 진단확정 시 가입금액을 최초 1회 지급합니다.
  · 면책기간 90일 (계약일로부터 90일 지난 다음날부터 보장)
  · 감액기간 1년 (보장개시 후 1년 미만 진단 시 50% 지급)
  · 가입한도 1억원 / 가입가능연령 15~70세
  · 갑상선암·제자리암 등 유사암은 별도 담보(CAN002)에서 보장

[나이 설명]
  여기서 '나이'는 만나이가 아니라 보험나이입니다.
  · 보험나이 = 계약일 기준 만나이, 6개월 미만은 버리고 6개월 이상은 1살 더함
  · 요율은 5세 단위 구간(40~44세)으로 적용되므로 44세→45세에서 단가가 한 번 점프
  · 이 담보는 5세 오를 때 요율이 평균 약 34% 오릅니다 (남성 40세→45세 기준)
```

### 1.2 입력 항목

| 항목 | 필수 | 예시 표현 | 미입력 시 처리 |
|---|---|---|---|
| 나이 | **필수** | `40세`, `40살`, `만 39세`, `85년생` | 되물음 ("나이를 알려주세요") |
| 담보 | **필수** | `암진단비`, `암`, `뇌졸중`, `입원일당` | 되물음 + 담보 후보 3개 제시 |
| 성별 | 권장 | `남`, `남자`, `여성` | 남/여 두 건 모두 표기 |
| 가입금액 | 선택 | `3천만원`, `3000만원`, `1억` | 담보별 기본 가입금액으로 계산 후 명시 |
| 납입기간 | 선택 | `20년납`, `30년납` | 20년납 기본 |
| 만기 | 선택 | `80세만기`, `100세만기` | 80세만기 기본 |

- 담보명은 **별칭(alias) 사전**으로 매핑한다. (예: `뇌졸중`·`뇌출혈`·`뇌경색` → `CVA001 뇌혈관질환진단비`)
- 별칭이 여러 담보에 걸리면 임의 선택하지 말고 후보를 제시하고 되묻는다.

### 1.3 산출 로직

```
월보험료 = 기준요율(담보코드, 성별, 연령구간)
         × 가입금액배수 (가입금액 ÷ 담보별 요율단위)
         × 납입기간계수
         × 만기계수
(원 단위 10원 절상, 갱신형 담보는 만기계수 미적용 + 갱신주기 명시)
```

- 요율단위는 담보 유형별로 다르다.
  - 진단비·사망·장해형: **가입금액 1,000만원당**
  - 입원일당형: **1일당 1만원당**
  - 수술비형: **1회당 10만원당**
- 계수 테이블(예시): 납입기간 10년 1.72 / 15년 1.31 / 20년 1.00 / 30년 0.78, 만기 80세 1.00 / 90세 1.26 / 100세 1.48

### 1.4 출력 구성 (고정 4블록)

1. **보험료** — 월보험료 + 적용 조건(납기/만기/갱신여부)
2. **산출 근거** — 적용 요율, 계산식 전개 (검증 가능해야 함)
3. **담보 설명** — 지급사유, 면책기간, 감액기간, 가입한도, 가입가능연령, 유의사항
4. **나이 설명** — 보험나이 정의, 적용된 연령구간, 구간 상승 시 인상률

> 담보 설명·나이 설명은 **자유 생성이 아니라 담보 마스터 데이터의 필드를 그대로 렌더링**한다. 데이터에 없는 내용을 지어내지 않는다.

### 1.5 예외 처리

| 상황 | 응답 |
|---|---|
| 가입가능연령 초과 | "해당 담보는 15~70세만 가입 가능합니다" + 대체 담보 안내 |
| 가입한도 초과 | 한도까지로 재계산 + 초과 사실 명시 |
| 요율표에 없는 조합 | 임의 보간 금지, "요율 미등재" 안내 후 담당자 문의 유도 |
| 담보명 인식 실패 | 후보 담보 3개 제시 |

### 1.6 면책 문구 (모든 보험료 답변 하단 고정)

> 본 금액은 사내 요율셋 기준 참고용 산출값이며, 실제 청약 보험료는 심사 결과·적용 상품·할인 조건에 따라 달라질 수 있습니다.

## 2. 기능 B — 신상품 문서 기반 답변 (검색 범위 분리)

### 2.1 핵심 원칙

**신상품 관련 질문은 "최신 상품 리스트"에 등재된 상품의 문서만 담은 인덱스에서만 검색해 답한다.**

- 문서 인덱스를 **2개로 분리**한다.
  - `index_latest` — **최신 상품 리스트에 있는 상품의 최신 개정 문서만** 적재 (기본 검색 대상)
  - `index_all` — 과거·단종·개정 이전 문서까지 전부 포함 (연관질문 클릭 등 명시적 요청 시에만 검색)
- 기본 검색 범위는 **항상 `index_latest`**다. `index_all`은 사용자가 명시적으로 요구했을 때만 열린다.

### 2.2 라우팅 규칙 (시점 언급 여부로 분기)

| 사용자 질문 | 검색 범위 | 근거 |
|---|---|---|
| "암보험 보장 어떻게 돼?" | `index_latest` | 시점 언급 없음 → 최신 상품만 |
| "지금 파는 암보험 뭐 있어?" | `index_latest` | 현재 시점 → 최신 상품만 |
| "**2022년** 암보험은 어땠어?" | `index_all` | 특정 시점 언급 |
| "예전 버전이랑 뭐가 달라졌어?" | `index_all` | 과거 지칭 표현 |
| "단종된 OO플랜 조건 알려줘" | `index_all` | 단종 상품 지칭 |

**시점 언급으로 판단하는 신호**
- 연도·기간: `2022년`, `재작년`, `3년 전`, `2021~2023`
- 과거 지칭어: `예전`, `과거`, `그때`, `이전 버전`, `구상품`, `개정 전`
- 상태 지칭어: `단종`, `판매중지`, `절판`
- 특정 버전/차수: `1종`, `2차 개정`, 구 상품명 직접 언급

**위 신호가 하나도 없으면 → 무조건 `index_latest`만 검색한다.** 최신 인덱스에서 근거를 못 찾아도 임의로 `index_all`로 확장하지 않고, "최신 상품 기준으로는 해당 내용을 찾지 못했습니다"라고 답한 뒤 연관질문으로 전체 검색을 유도한다.

### 2.3 답변 표기 요건

- 답변 상단에 **검색 범위 배지**를 표시한다. `🟢 최신 상품 기준` / `🗂 전체 문서 기준(과거 상품 포함)`
- 근거 문서는 **문서명 + 상품명 + 개정일(또는 판매개시일) + 페이지/조항**까지 표기한다.
- `index_all` 결과를 인용할 때는 **"현재 판매 중이 아닌 상품입니다"** 를 문장 단위로 명시한다.

### 2.4 데이터 운영 요건

- **최신 상품 리스트**는 상품팀이 관리하는 단일 원본(마스터)에서 가져온다. AI가 판단해 목록을 추론하지 않는다.
- 상품 단종/개정 시: 해당 문서를 `index_latest`에서 제거하고 `index_all`로만 남긴다. (동기화 주기: 일 1회 이상)
- 리스트 갱신 이력(추가·제외 일자)을 남겨 답변 시점 기준 검증이 가능해야 한다.

## 3. 연관질문 3개 노출 규칙

### 3.1 공통

- 모든 답변 하단에 **연관질문 정확히 3개**를 노출한다.
- 각 연관질문은 클릭 시 그대로 재질의되며, **검색 범위 플래그(`scope`)를 함께 전달**한다.

### 3.2 최신 상품 범위(`index_latest`)로 답한 경우 — **필수 규칙**

**3개 중 1개는 반드시 "전체 문서 검색" 유도 질문으로 고정 배치한다.**

- 배치: 3번째 슬롯 고정
- 클릭 시 `scope = all` 로 전환되어 `index_all` 검색 실행
- 문구 예시 (맥락에 맞춰 택1)
  - "과거 상품까지 포함해서 다시 찾아볼까요?"
  - "예전에 판매하던 암보험 담보도 함께 확인할까요?"
  - "단종·개정 이전 문서에서도 검색해볼까요?"
- 나머지 2개는 현재 답변 맥락을 심화하는 질문으로 생성 (예: 인접 담보, 가입조건, 면책사항)

### 3.3 전체 문서 범위(`index_all`)로 이미 답한 경우

- 전체 검색 유도 질문은 노출하지 않는다(중복).
- 대신 **"최신 상품 기준으로 보기"** 를 1개 넣어 되돌아갈 수 있게 한다.

### 3.4 보험료 답변의 연관질문

- 예: "50세로 계산하면 얼마인가요?" / "100세만기로 바꾸면?" / "뇌혈관질환진단비도 같이 볼까요?"
- 이 경우에도 상품 문서를 인용했다면 3.2 규칙을 동일하게 적용한다.

## 부록 A. 담보 마스터 스키마 (예시)

전체 샘플: `docs/samples/coverage_master_sample.json` (담보 10종)

```json
{
  "code": "CAN001",
  "name": "암진단비(유사암 제외)",
  "aliases": ["암", "암진단", "일반암"],
  "category": "진단비",
  "unit_type": "amount",
  "summary": "암(유사암 제외) 진단확정 시 가입금액을 1회 지급",
  "payout_trigger": "진단확정 시 최초 1회 가입금액 100% 지급",
  "waiting_days": 90,
  "reduction_period_days": 365,
  "reduction_rate": 0.5,
  "renewal_cycle_years": null,
  "issue_age": { "min": 15, "max": 70 },
  "limit_won": 100000000,
  "notes": ["면책 90일", "1년 미만 진단 시 50% 감액"]
}
```

- `summary` / `payout_trigger` / `notes` 가 **담보 설명 블록의 원천**이다.
- `waiting_days`, `reduction_period_days`, `issue_age`, `limit_won` 은 **예외 처리 판정에도 사용**된다.

## 부록 B. 요율 테이블 스키마 (예시)

```json
{
  "unit": { "amount": 10000000, "daily": 10000, "per_event": 100000 },
  "basis": "월납 / 20년납 / 80세만기 / 비갱신",
  "rates": {
    "CAN001": {
      "M": { "35-39": 3130, "40-44": 4200, "45-49": 5630 },
      "F": { "35-39": 4480, "40-44": 5600, "45-49": 6720 }
    }
  }
}
```

- 키 구조: `담보코드 → 성별(M/F) → 연령구간(5세)`
- 연령구간 사이 보간은 하지 않는다(미등재 조합은 "요율 미등재" 처리).

## 부록 C. 나이(보험나이) 규칙

- **보험나이 = 계약일 기준 만나이**, 단 **6개월 미만 절사 / 6개월 이상 1세 가산**
  - 예: 1985-03-10생, 계약일 2026-09-01 → 만 41세 5개월 → 보험나이 **41세**
  - 예: 1985-01-10생, 계약일 2026-09-01 → 만 41세 7개월 → 보험나이 **42세**
- 요율은 **5세 단위 구간**으로 적용 → 구간 경계(44→45세)에서 단가가 계단식으로 상승
- 나이가 오를수록 보험료가 오르는 이유: 해당 연령의 **발생률(위험률)** 이 높아지기 때문이며, 담보별 상승폭이 다르다.
  - 상승폭 큼: 장기요양, 뇌혈관, 허혈성심장, 일반사망
  - 상승폭 작음: 상해수술비 (사고 위험은 연령 의존도가 낮음)
- 답변에서는 **"적용된 구간 + 다음 구간 대비 인상률"** 을 함께 안내한다.

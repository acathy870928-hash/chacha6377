## 1. 연관질문이 보험과 무관한 주제로 생성되는 현상

**[이슈]**
"강아지가 무지개다리를 건너면 펫보험에서 보상이 되나요?"라는 질의에 대해 답변은 정상적으로 제공되었으나, 이후 아래와 같이 보험과 직접적인 관련이 없는 연관질문 3건이 노출되는 것을 확인했습니다. (9/1 확인)

- 무지개 다리 전설은 어디서 유래했나요?
- 무지개 다리 전설이 현대 문화에 미친 영향은?
- 무지개 다리 전설이 반려동물 문화에 주는 의미는?

답변 자체의 오류라기보다, 현재 채널에서 답변하기 어려운 질문을 AI가 후속 질문으로 제안하는 문제로 보고 있습니다.
사용자는 AI가 제시한 연관질문을 답변 가능한 질문으로 인식할 수 있어 서비스 신뢰도에 영향을 줄 수 있으므로 우선 검토를 요청드립니다.

**[요청]**
연관질문이 각 채널의 서비스 범위 및 실제 답변 가능한 범위 내에서만 생성되도록 개선 부탁드립니다.

## 2. 교육자료·소식지 내 보험료 수치 노출

**[이슈]**
현재 교육자료 및 소식지 일부에 보험료가 구체적인 수치로 기재되어 있어 답변에 노출될 가능성이 있습니다.
해당 데이터는 현재 삭제를 진행하고 있으며, 별도의 보험료 데이터셋이 구축되기 전까지는 구체적인 보험료 금액이 답변에 노출되지 않도록 관리할 예정입니다.
보험료 관련 답변 문구 및 제한 기준은 저희 측에서 별도로 보강하겠습니다.

**[확인 요청]**
보험료 안내용 데이터를 별도 Excel 파일로 구성하여 업로드할 경우, 해당 파일을 보험료 질의에 대한 전용 또는 우선 검색 데이터로 지정할 수 있는지 확인 부탁드립니다.
예를 들어 보험사 / 상품명 / 담보명 / 연령대 / 가입금액 / 보험료 등의 항목을 정형화하여 제공하고, 보험료 관련 질의가 들어오는 경우 다른 교육자료나 소식지가 아닌 해당 Excel 데이터를 기준으로 조회·답변하도록 구성할 수 있는지 검토 부탁드립니다.

향후에는 동일한 보험료 데이터를 저희 측 시스템에서 API 형태로 제공하는 방안도 검토하고 있습니다.
Excel 기반 조회 이후 API 방식으로 전환하거나 병행하는 것이 가능한지 확인 부탁드립니다.
가능할 경우 필요한 API 요청·응답 규격, 연동 방식, 실시간 조회 가능 여부에 대해서도 의견 부탁드립니다.

## 3. 상품 질의 시 판매종료 상품이 함께 검색되는 현상

**[이슈]**
이전 회의에서도 논의된 사항입니다.
신규 제안·추천·비교와 같이 현재 판매상품을 기준으로 답변해야 하는 질의에도 판매종료 상품이 함께 검색되어 현행 상품 안내에 오용될 가능성이 있습니다.
반면 보유계약의 약관 해석이나 특정 가입시점을 명시한 과거 상품 조회의 경우에는 판매종료 상품을 포함한 전체 검색이 필요하므로, 질의 유형에 따라 검색 범위를 구분하는 방식이 필요합니다.

**[현재 상황]**
현재 색인된 문서에는 판매시점이나 현재 판매 여부를 구분할 수 있는 메타데이터가 없는 상태입니다.
저희 측에서 제공 가능한 자료는 현재 판매상품 마스터(Excel / 보험사 / 상품명 / 약 [ ]종) 수준이며, 판매종료일 데이터는 보유하고 있지 않습니다.
따라서 현시점에서는 해당 마스터에 포함되어 있는지를 기준으로 현재 판매상품 여부를 판단할 수 있습니다.
현재 판매상품 요약서는 믹키에 업로드할 예정이며, 해당 자료에 대한 별도 청킹 작업은 요청드리지 않습니다.

**[검토 요청]**
위와 같은 데이터 제약 하에서 현재 판매상품과 판매종료 상품을 구분하여 검색할 수 있는 방안이 있을지 검토 부탁드립니다.
예를 들어 현재 판매상품을 묻는 질의에서는 제공드리는 현재 판매상품 마스터를 기준으로 검색 대상을 제한하고, 과거 가입상품이나 특정 시점의 상품을 묻는 경우에는 기존 전체 데이터를 검색하는 방식 등이 가능한지 의견 부탁드립니다.
제공 가능한 자료가 제한적인 만큼, 벨루가 측에서 보시기에 보다 적절한 구현 방식이나 추가로 필요한 데이터가 있다면 함께 제안 부탁드립니다.

## 4. 회신 요청 사항

작업 착수 전 내부 검토를 위해 각 항목별로 아래 사항을 먼저 확인하고자 합니다.

- 진행 가능 여부
- 가능한 경우 적용 또는 구현 방식
- iFA 측에서 추가로 제공해야 할 자료 및 준비 사항
- 예상 소요 기간

검토 후 회신 부탁드립니다.

## 부록 B. 선택 추가 문장 (필요한 것만 붙여 쓰기)

1. **2번, 색인 삭제 반영 확인** (원본 삭제만으로는 답변 노출이 계속될 수 있음)
   "참고로 삭제 중인 교육자료·소식지의 보험료 수치는 원본 삭제와 별개로 검색 색인에서도 제거되어야 하므로, 삭제 반영 절차(재색인 필요 여부, 반영 시점)를 함께 확인 부탁드립니다."

2. **2번, 정형 조회 세부 동작** (조건 누락·데이터 갱신 처리)
   "보험료 데이터 조회 시 연령·가입금액 등 조건이 질의에 포함되지 않은 경우의 처리 방식(재질문 등)과, 보험료 개정 시 데이터 갱신 주기 및 이력 관리 방식도 함께 제안 부탁드립니다."

3. **3번, 매칭 키 사전 제안** (마스터와 색인 문서를 잇는 열을 iFA가 보강 가능함을 명시)
   "마스터와 색인 문서 간 매칭을 위해 저희가 마스터에 추가할 수 있는 항목(상품코드, 문서명, 판매개시일 등)이 있다면 알려주시면 반영하겠습니다."

4. **2·3번 공통, 채널별 기준 차등** (고객용·대외용은 더 보수적으로)
   "채널별로 적용 기준을 달리하는 것이 적절하다고 판단되는 경우(예: 고객용·대외용 채널의 보험료 노출 제한, 판매종료 상품 검색 범위 등) 채널별 제안도 함께 부탁드립니다."

5. **4번, 회신 기한**
   "내부 일정 조율을 위해 ○월 ○일까지 회신 부탁드립니다."

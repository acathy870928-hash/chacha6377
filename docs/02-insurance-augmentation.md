# 02. Insurance Value Augmentation

## 🙏 우리는 무엇을 증강하는가?

iFA AI & Co.는 보험의 전 여정에서 **6가지 가치**를 증강합니다.

| 증강 영역 | 정의 | 핵심 수단 |
|-----------|------|-----------|
| **Knowledge Augmentation** | 보험전문가 수준의 지식을 누구나 활용할 수 있도록 합니다. | Insurance Vertical AI™ |
| **Decision Augmentation** | 고객이 최고의 보험 의사결정을 내릴 수 있도록 지원합니다. | 보험 의사결정 엔진 |
| **Protection Augmentation** | MediCode 기반 AI 설계를 통해 보장의 가치를 극대화합니다. | MediCode |
| **Retirement Augmentation** | VFA와 HopePlan을 통해 은퇴소득과 연금의 가치를 극대화합니다. | VFA, HopePlan |
| **Legacy Augmentation** | Legacy Plan을 통해 가족의 자산승계를 최적화합니다. | Legacy Plan |
| **Service Augmentation** | 보험 가입 이후에도 AI가 지속적으로 고객을 관리합니다. | AI Link, Agentic AI |

---

### Knowledge Augmentation

보험전문가 수준의 지식을 누구나 활용할 수 있도록 합니다.
보험 지식, 보험법령, 보험상품, 보험약관, 보험 실무에 대한 전문성을 AI로 개방합니다.

### Decision Augmentation

고객이 최고의 보험 의사결정을 내릴 수 있도록 지원합니다.
분석 → 비교 → 추천의 전 과정을 객관적이고 데이터 기반으로 수행합니다.

### Protection Augmentation

**MediCode** 기반 AI 설계를 통해 보장의 가치를 극대화합니다.
건강검진 데이터와 유전자 분석 데이터를 활용하여 개인별 위험을 분석하고 보장을 최적화합니다.

### Retirement Augmentation

**VFA** 와 **HopePlan** 을 통해 은퇴소득과 연금의 가치를 극대화합니다.
변액보험·변액연금의 수익률 관리부터 은퇴소득 설계, 절세 전략, 연금 최적화까지 지원합니다.

### Legacy Augmentation

**Legacy Plan** 을 통해 가족의 자산승계를 최적화합니다.
상속 전략, 증여 전략, 가족 자산 이전 계획을 AI로 설계합니다.

### Service Augmentation

보험 가입 이후에도 AI가 지속적으로 고객을 관리합니다.
계약 유지관리, 연금 관리, 상속 계획까지 평생에 걸친 관리를 제공합니다.

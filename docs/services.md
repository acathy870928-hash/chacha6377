## 2. ORCA Ai — FA용 AI

### 해결하는 문제

> 보험은 매일 변화합니다. 새로운 상품이 끊임없이 출시되고, 기존 상품의 약관도 개정됩니다.
> 이 모든 상품을 빠짐없이 파악하고, 사내 제도와 교육 내용까지 숙지하는 것은 FA에게 결코 쉬운 일이 아닙니다.

> 고객 앞에서 답이 막히면 지금까지는 "확인해서 연락드리겠습니다"였고,
> 되묻고 다시 연락하는 사이 **상담의 흐름은 이미 끊깁니다.**
> ORCA Ai는 24시간 열려 있습니다. 밤이든 주말이든, 그 자리에서 확인하고 그 자리에서 해결합니다.

### 연결 데이터

| 데이터 | 내용 | 시점 |
| --- | --- | --- |
| **Micky DATA** | 보험이론·재무학·금융법령, 정부기관·보험회사·연구기관 자료 | 현재 |
| **BumE_F DATA** | 사내 제도·행사·교육 및 FA 세일즈 자료 | 현재 |
| **External MCP** | 법령, 공공데이터, 제휴 데이터 | 수시 추가 |
| **VELUGA DATA** | 보험상품·상품방법서·상품해설서 등 보험약관 데이터 → **특정 상품 정확한 안내 가능** | **10/1** |
| **Cloud DATA** | 계약체결정보·관리정보·수수료 내역 → 담당 계약 단계, 이번 달 수수료를 클라우드에 따로 들어가지 않고 ORCA Ai에서 바로 확인 | 이후 |

## 3. Ai Link — 고객용 AI

### 만든 이유

> 우리에게는 이미 좋은 고객용 서비스가 여럿 있었습니다.
> **문제는 각각 다른 문 뒤에 있었다는 것입니다.**
> 그래서 기존 고객용 콘텐츠를 하나로 통합하고 그 위에 AI 챗봇을 얹었습니다.

담당 FA의 이름이 붙은 「○○○의 Ai Link」 페이지로 전달되며,
고객이 평소 쓰는 말로 질문하면 답변하고 필요한 서비스로 바로 연결합니다.

### 서비스 3갈래

| 구분 | 서비스 | 증강 영역 |
| --- | --- | --- |
| **맞춤 분석** | **메디코드 보험설계** / 변액보험 펀드 추천(**VFA**) | Protection · Retirement |
| **보험 관리** | 내보험 찾기 / 다이렉트 보험 / 빠른 보험금 청구 / 숨은 보험금 찾기 | Service |
| **계산기·조회** | 연금 계산기 / 상속증여 계산기 / 변액보험 수익률 조회 | Retirement · Legacy |

> **확정(2026-08-21)**: 「AI 질병예측」은 별도 서비스로 두지 않고 **메디코드로 단일화**합니다.
> 질병 발생 가능성 예측은 메디코드 보험설계의 분석 단계입니다.

### 연결 데이터

| 데이터 | 내용 | 시점 |
| --- | --- | --- |
| **Micky DATA** | 보험에 관한 일반 궁금증 답변 | 현재 |
| **BumE_C DATA** | 아이에프에이 고객에게 필요한 데이터 | 현재 |
| **Cloud DATA** | 로그인 시 iFA 클라우드 연동 — 본인 보험가입 내역·서비스 신청 이력 즉시 조회 | 현재 |
| **VELUGA DATA** | 보험약관 데이터 | **10/1** |
| **My DATA** | 전송요구권 기반. 타사 가입 보험 + 건강검진·진료기록 등 의료정보 | 다음 단계 |

> **My DATA의 의미**
> 지금 조회되는 것은 아이에프에이를 통해 가입한 내역뿐입니다.
> 마이데이터까지 연결되면 **고객의 보장 전체를 놓고** 개인에 맞춘 안내가 가능해집니다.
> — 이것이 MediCode가 온전히 작동하기 위한 전제 조건입니다.

### FA 운용

- 「관리하기」에서 나의 Ai 명함 주소 복사 / QR 코드 제공
- 카카오톡 오픈채팅 링크 등록, 배경색 변경
- **고객이 어떤 서비스를 사용했는지 담당 FA에게 표시** → 보고 먼저 연락 가능

## 4. 데이터 연결 타임라인

```
현재        Micky · BumE_F · BumE_C · Cloud(고객 조회) · External MCP
  │
10/1  ───► VELUGA DATA (보험약관)      ORCA Ai + Ai Link 동시
  │         → 특정 상품에 대한 정확한 안내
  │
이후  ───► Cloud DATA (FA)             계약 단계 · 수수료를 ORCA Ai에서 직접
  │
다음  ───► My DATA (마이데이터)         타사 보험 + 의료정보
            → 보장 전체를 놓고 개인 맞춤 안내 (MediCode 완성 조건)
```

> 벨루가 구축 6개월 차수의 **상품DB 우선 연동**이 곧 VELUGA DATA 연결입니다.
> 즉 10/1 연결과 6개월 구축은 **같은 트랙**입니다. → [Architecture](architecture.md)

## 5. 커뮤니케이션 원칙

FA 안내문이 취한 태도를 표준으로 삼습니다.

> **"AI 서비스는 미완성입니다. 시대에 맞춰 데이터를 더하며 계속 발전해 나갈 예정입니다.
> 많이 사용해 주시고, 부족한 점을 적극적으로 알려 주시기 바랍니다."**

- **완성됐다고 말하지 않는다.** 미완성임을 먼저 밝히는 것이 [Charter 제6조](charter.md)와 같은 태도입니다.
- **먼저 시작했음을 말하되 자랑하지 않는다.** "남은 일은 시작이 아니라 더 잘 쓰는 것입니다."
- **로드맵을 날짜와 함께 말한다.** 10월 1일처럼 구체적인 시점이 신뢰를 만듭니다.

# AI 데이터 구조 (AX팀 공유 기준)

챗봇이 답변에 사용하는 데이터의 전체 구조. AX팀 공유 내용을 기준으로 정리하며,
자료 업로드 방법(유효기간 설정 · 태그 체계)은 추후 공유 예정이므로 TBD로 둔다.

## 대원칙

AI는 가지고 있는 자료만큼만 답한다. 따라서 데이터 소스의 종류와 **시점(언제 기준 자료인가)**이
답변 품질을 결정한다. 지난 기준으로 답하는 것은 답하지 않는 것보다 위험하다.

## 두 갈래 구분

데이터는 처리 방식에 따라 두 가지로 갈리며, **응답 방식이 서로 다르다.**

| 구분 | 비유 | 성격 | 응답 방식 |
| --- | --- | --- | --- |
| **찾아 읽는 자료** (검색형) | 도서관에서 책을 찾아 읽고 설명 | 글로 정리된 자료. 상대적으로 정적 | AI가 관련 부분을 찾아 **이해해서 설명** |
| **시스템에서 불러오는 정보** (API형) | 서랍을 열어 서류를 꺼내옴 | 사람마다 다르고 매일 바뀌는 값 | 실제 값을 **그대로 표시** |

이 구분이 중요한 이유: 「내 수수료가 얼마인가」 같은 질문은 API로 가져온 실제 값만 보여주며,
AI가 임의로 생성해 답하는 일이 없어야 한다.

- 검색형 소스: Micky DATA / VELUGA DATA / External MCP / BumE_C / BumE_F
- API형 소스: My DATA / Cloud DATA

## 데이터 소스 목록

### 검색형 (찾아 읽는 자료)

| # | 소스 | 분류 | 대상 | 내용 |
| --- | --- | --- | --- | --- |
| 1 | **Micky DATA** | 보험 전문지식 | FA, 고객 (외부공개 가능) | 보험이론, 재무학, 금융법령, 정부기관·보험회사·연구기관 자료 등 보험산업 전문지식 |
| 2 | **VELUGA DATA** | 보험약관 자료 | FA, 고객 (외부공개 가능) | 보험상품, 보험약관, 상품방법서, 상품해설서 |
| 3 | **External MCP** | 외부 자료 연결 | FA, 고객 (외부공개 가능) | 공공데이터, 금융법령·판례, 보험기사, 변액보험 수익률 및 벤치마크 자료 등 |
| 5 | **BumE_C** | 회사 자료 | 고객 | 아이에프에이 고객전용서비스 안내 |
| 6 | **BumE_F** | 회사 자료 | FA | 사내 규정·제도 및 교육·행사 안내 |

- **External MCP**: 회사 밖 자료를 AI가 가져올 수 있도록 연결해 둔 통로. 새 자료가 생기면
  통로에 추가하는 방식이라 소스가 계속 늘어난다 → 소스 목록을 하드코딩하지 않고
  레지스트리로 관리해야 한다.

### API형 (시스템에서 불러오는 정보)

| # | 소스 | 대상 | 내용 |
| --- | --- | --- | --- |
| 4 | **My DATA** | 고객 | 고객이 자신의 정보를 확인. 전송요구권을 근거로 여러 기관에 흩어진 본인 정보(보험가입내역, 금융정보, 건강검진 진료기록 등)를 한곳에 모으는 제도 |
| 7 | **Cloud DATA** | FA / 관리자 / 스태프 | iFA 클라우드에서 처리하던 업무를 AI에서 바로 확인<br>· FA: 계약체결정보, 관리정보, 수수료 내역, 스타투어 정보<br>· 관리자: 조직관리 업무 시스템(ERP) 메뉴<br>· 스태프: 스태프 업무 시스템(ERP) 메뉴 |

## 설계에 반영해야 할 점

1. **응답 경로 분리** — 질문을 검색형/API형으로 라우팅하고, API형 답변에는 AI 생성 텍스트가
   값 자체를 대체하지 않도록 한다.
2. **대상(권한) 기반 필터링** — 소스마다 대상이 다르다(고객 / FA / 관리자 / 스태프).
   같은 질문이라도 사용자 역할에 따라 접근 가능한 소스가 달라진다.
3. **출처 표기** — 검색형 답변은 어느 소스의 어느 문서를 근거로 했는지 함께 제시한다.
   특히 약관(VELUGA DATA)은 조항 단위 근거가 필요하다.
4. **시점 관리** — 자료를 넣는 일보다 시기별로 관리하는 일이 더 큰 과제.
   유효기간이 지난 자료가 검색 결과에 섞이지 않도록 인덱스 단계에서 걸러야 한다.

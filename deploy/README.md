# 서버에 올리기

윈도우 쓰시는 분 기준으로, 서버 한 대에 올려서 FA들이 카톡으로 받아보게 만드는 순서입니다.
**대표님이 하실 일은 3개**뿐이고, 나머지는 스크립트가 알아서 합니다.

---

## 대표님이 준비하실 것

### 1. 클라우드 서버 한 대

국내 업체 아무거나 괜찮습니다. 가입하고 서버를 하나 만드세요.

| 항목 | 고를 것 |
|---|---|
| 운영체제 | **Ubuntu 22.04** 또는 **24.04** |
| 사양 | 제일 작은 것 (CPU 1개 / 메모리 1GB) — 충분합니다 |
| 요금 | 월 5천 ~ 1만원대 |

만들고 나면 **서버 IP 주소**(예: `123.45.67.89`)와 **접속 비밀번호**를 받게 됩니다.
이 두 개를 메모해 두세요.

> 국내 업체는 네이버 클라우드, 카페24, 가비아, 스마일서브 등이 있고
> 해외는 Vultr, DigitalOcean 이 저렴합니다. 어디든 상관없습니다.

### 2. 도메인 (선택이지만 권장)

`news.우리사업단.co.kr` 같은 주소입니다. 연 1~2만원입니다.

**왜 필요하냐면** — 카톡 인앱 브라우저는 도메인 없는 주소(`http://123.45.67.89`)에
"안전하지 않음" 경고를 띄웁니다. FA들이 링크를 눌렀을 때 경고가 뜨면 안 누릅니다.

#### 가비아에서 산 도메인 연결하기

1. [my.gabia.com](https://my.gabia.com/dashboard) 로그인
2. 왼쪽 메뉴 **서비스 관리 → 도메인** 에서 산 도메인 클릭
3. **DNS 정보 → DNS 관리 → 설정** 으로 들어갑니다
4. **레코드 수정** 을 누르고 아래처럼 한 줄 추가한 뒤 저장

   도메인이 `ifanews.co.kr` 이라면 **두 줄**을 넣습니다.

   | 타입 | 호스트 | 값/위치 | TTL |
   |---|---|---|---|
   | `A` | `@` | `서버 IP 주소` | `600` |
   | `A` | `www` | `서버 IP 주소` | `600` |

   `@` 는 도메인 전체(`ifanews.co.kr`), `www` 는 `www.ifanews.co.kr` 입니다.
   둘 다 걸어두면 FA가 어느 쪽으로 들어와도 열립니다.
   설치할 때 도메인을 `ifanews.co.kr` 로만 넣으면 `www` 는 자동으로 같이 잡습니다.

5. 저장 후 **10~30분** 기다립니다. 반영됐는지는 PowerShell에서 확인할 수 있습니다.

   ```powershell
   nslookup ifanews.co.kr
   ```

   결과에 서버 IP가 나오면 된 겁니다. **이게 나온 뒤에 설치를 시작하세요** —
   먼저 하면 HTTPS 인증서 발급이 실패합니다.

> ⚠️ **가비아 "웹호스팅"은 이 프로그램을 돌릴 수 없습니다.**
> 웹호스팅은 PHP 같은 것만 올릴 수 있고 SSH 접속과 프로그램 상시 실행이 안 됩니다.
> **"클라우드 서버" 또는 "가상서버(VPS)"** 여야 합니다. 관리 화면에서 `root` 로 SSH 접속이
> 되는지 확인해 보세요.

### 3. 관리자 비밀번호 정하기

대표님이 어드민에 로그인할 때 쓸 비밀번호입니다. 8자 이상. 설치 중에 물어봅니다.

> **비밀번호는 아무에게도 보내지 마세요.** 설치에 나오는 비밀번호는 세 종류인데,
> 전부 대표님이 대표님 화면에서 직접 입력하는 것입니다.
>
> | 무엇 | 어디서 났나 | 어디에 넣나 |
> |---|---|---|
> | 서버 접속 비밀번호 | 서버 업체가 발급 | PowerShell 의 `ssh` 접속 화면 |
> | 관리자 비밀번호 | 대표님이 지금 정함 | 설치 중 질문에 입력 |
> | 가비아 로그인 | 가비아 가입할 때 정함 | 가비아 사이트에서만 |
>
> 채팅이나 메일로 옮겨 적을 일이 없습니다.

## 설치하기

### 1단계 — 소스를 서버에 올립니다

이 저장소는 **비공개**라 서버에서 바로 내려받을 수 없습니다. 윈도우에서 한 번 올려주셔야 합니다.

**(1) ZIP 내려받기** — 브라우저에서 아래 주소로 들어가 초록색 **Code** 버튼 → **Download ZIP**

```
https://github.com/acathy870928-hash/chacha6377/tree/claude/kakaotalk-chatbot-news-sharing-rg091w
```

`다운로드` 폴더에 `chacha6377-....zip` 이 생깁니다. **압축을 풀어주세요.**

**(2) 서버로 보내기** — 윈도우 **PowerShell**을 엽니다. (시작 버튼 → `powershell` 검색)

```powershell
cd $HOME\Downloads
scp -r .\chacha6377-claude-kakaotalk-chatbot-news-sharing-rg091w root@서버IP:/root/news-src
```

`서버IP` 자리에 받으신 IP를 넣으세요. 폴더 이름이 다르면 `dir` 로 확인 후 맞춰주시면 됩니다.
비밀번호를 물으면 넣으세요. (**화면에 안 보이는 게 정상**입니다.)

### 2단계 — 서버에 접속해서 설치

```powershell
ssh root@서버IP
```

처음 접속하면 `Are you sure you want to continue connecting?` 이라고 묻습니다. `yes` + 엔터.

접속된 검은 화면에 이 한 줄을 붙여넣으세요:

```bash
sudo bash /root/news-src/deploy/install.sh
```

그러면 세 가지를 물어봅니다. 준비하신 걸 넣으시면 됩니다.

```
도메인 (예: ifanews.co.kr / 여러 개면 띄어쓰기로 / 없으면 그냥 엔터):
관리자 비밀번호 (대표님이 어드민에 로그인할 때 씁니다):
사업단 이름 (화면과 브리핑 제목에 나옵니다) [사업단]:
```

5~10분 기다리면 끝납니다. 마지막에 접속 주소가 나옵니다.

> **더 간단하게 하고 싶으시면** — GitHub에서 저장소를 공개(public)로 바꾸면 ZIP 올리는 과정 없이
> 서버에서 명령 한 줄로 끝납니다. 비밀번호와 기사 DB는 저장소에 없으니 새어나갈 건 코드뿐입니다.
> 다만 공개 여부는 대표님이 정하실 일이라 기본은 비공개 기준으로 적었습니다.

### 3단계 — 들어가 보기

브라우저에서 `https://내도메인/admin` 으로 들어가 방금 정한 비밀번호로 로그인하세요.
기사가 이미 쌓여 있으면 성공입니다.

## 설치가 끝나면

- **기사는 30분마다 자동으로 수집됩니다.** 따로 켜둘 것 없습니다.
- **서버가 재부팅돼도 자동으로 다시 켜집니다.**
- 새 버전이 나오면 **1단계(ZIP 올리기)를 다시 하고** `sudo bash /root/news-src/deploy/install.sh` 를 실행하면 됩니다.
  **기사와 비밀번호는 그대로 유지됩니다** — 프로그램 파일만 바뀝니다.

### 알아두시면 좋은 명령

| 하고 싶은 것 | 명령 |
|---|---|
| 다시 켜기 | `sudo systemctl restart news-briefing` |
| 잘 돌고 있나 확인 | `sudo systemctl status news-briefing` |
| 무슨 일이 있었나 보기 | `sudo journalctl -u news-briefing -f` |
| 지금 당장 기사 수집 | `sudo -u news /srv/news-briefing/.venv/bin/python /srv/news-briefing/scripts/collect.py` |
| 다음 수집 시각 | `sudo systemctl list-timers news-collect` |

### 백업

챙길 파일은 **`/srv/news-briefing/data/news.db` 하나**입니다. 기사도 브리핑도 다 여기 들어 있습니다.

윈도우로 내려받으려면 PowerShell에서:

```powershell
scp root@서버IP:/srv/news-briefing/data/news.db .
```

## 잘 안 될 때

**`ssh` 에서 접속이 안 될 때** — 서버 업체 화면에서 방화벽에 22번 포트가 열려 있는지 확인하세요.
업체에 따라 기본으로 막아둡니다.

**HTTPS 인증서 발급이 실패했을 때** — 도메인이 아직 서버를 안 가리키고 있는 겁니다.
A 레코드 설정 후 10~30분 기다렸다가 다시:

```bash
sudo certbot --nginx -d 내도메인
```

**기사가 안 쌓일 때** — RSS 주소가 안 맞는 경우입니다. 아래로 확인하세요:

```bash
sudo -u news /srv/news-briefing/.venv/bin/python /srv/news-briefing/scripts/collect.py
```

어느 매체가 실패하는지 나옵니다. `/srv/news-briefing/feeds.json` 에서 주소를 고치면 됩니다.

**화면이 안 열릴 때** — 서버 업체 방화벽에서 80, 443 포트를 여세요.

## 보안 관련해서 알아두실 것

- **브리핑 링크는 아는 사람이면 누구나 봅니다.** 비밀번호가 없습니다.
  단톡방에 뿌리는 용도라 그렇게 만들었습니다. 대외비 내용은 넣지 마세요.
- 어드민(`/admin`)만 비밀번호로 잠깁니다.
- 기사 저작권 — 원문 전체를 옮겨 보관하므로, 사업단 내부 공유 범위를 넘어
  외부에 공개하시려면 해당 언론사와 협의가 필요할 수 있습니다.

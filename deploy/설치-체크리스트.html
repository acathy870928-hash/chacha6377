구글 클라우드에 올리는 순서

위에서부터 하나씩 하시면 됩니다. 체크는 저장되니 창을 닫았다 열어도 그대로입니다. 막히면 그 화면을 캡처해서 보여주세요.

왜 구글 클라우드로 바꿨나
  • 한국식 본인인증이 없습니다 — 구글 계정과 카드만 있으면 됩니다
  • PowerShell을 안 씁니다 — 브라우저 안에서 접속과 파일 올리기가 다 됩니다
  • 신규 $300 크레딧(90일), 미국 리전은 그 뒤에도 월 0원
0 / 0

1 구글 클라우드 가입

console.cloud.google.com 에서 구글 계정으로 로그인합니다.

카드를 등록해야 하지만 $300 크레딧이 먼저 쓰입니다. 크레딧이 남아 있는 동안은 카드에서 빠져나가지 않습니다.

2 서버(VM) 만들기

왼쪽 위 ☰ 메뉴 → Compute Engine → VM 인스턴스. 처음 들어가면 API 사용 설정에 1~2분 걸립니다.

인스턴스 만들기 를 누르고 아래대로 맞춥니다.

항목고를 값
이름news
리전us-central1 (아이오와)
영역us-central1-a
머신 계열E2
머신 유형e2-micro
리전을 서울로 하면 무료가 아닙니다. 첫 시간부터 과금됩니다. 반드시 us-central1 이어야 합니다.

이 둘을 안 켜면 FA 폰에서 안 열립니다. 나중에 따로 설정하려면 훨씬 번거롭습니다.

맨 아래 만들기. 1분쯤 뒤 목록에 news 와 외부 IP 가 나옵니다.

3 IP 고정하기

그냥 두면 서버를 껐다 켤 때 IP가 바뀝니다. 그러면 도메인 연결이 끊어집니다.

☰ 메뉴 → VPC 네트워크 → IP 주소 로 갑니다. news 서버의 외부 IP 줄에서 임시 → 고정 으로 바꿉니다. (오른쪽 ⋮ → 고정 주소로 승격)

서버에 붙어 있는 고정 IP 는 무료입니다. 다만 서버를 지우고 IP 만 남기면 요금이 붙으니, 나중에 정리하실 땐 같이 지우세요.

4 도메인 연결

가비아 DNS 관리 에서 ifanews.co.kr 을 그 IP로 연결합니다.

타입호스트값 / 위치TTL
A@서버 IP 주소600
Awww서버 IP 주소600

반영됐는지 확인 — 윈도우 PowerShell 에 붙여넣으세요. (이 단계에서만 씁니다)

nslookup ifanews.co.kr
결과에 서버 IP 가 나온 뒤에 다음으로 가세요. 먼저 하면 HTTPS 인증서 발급이 실패합니다. 반영까지 10~30분 걸립니다.

5 프로그램 올리기

저장소가 비공개라 서버가 직접 받을 수 없습니다. 한 번만 올려주시면 됩니다.

(1) ZIP 받기

브라우저에서 아래로 들어가 초록색 Code → Download ZIP. 압축은 풀지 마세요. ZIP 파일 그대로 씁니다.

https://github.com/acathy870928-hash/chacha6377

(2) 브라우저에서 서버 접속

VM 인스턴스 목록에서 news 줄의 SSH 버튼을 누릅니다. 검은 창이 새 창으로 열립니다. 비밀번호도 안 물어봅니다.

(3) ZIP 올리기

그 검은 창 오른쪽 위 ⚙ (톱니바퀴) → 파일 업로드 → 받으신 ZIP 파일을 고릅니다.

올라간 파일은 홈 폴더에 들어갑니다. 창 아래에 완료 메시지가 뜹니다.
